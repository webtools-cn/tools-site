输入净利润、营业收入、利息费用、所得税、折旧和摊销，即可自动计算EBITDA和EBITDA利润率。

公式：EBITDA = 净利润 + 利息 + 所得税 + 折旧 + 摊销。EBITDA利润率 = EBITDA ÷ 营业收入 × 100%。

常见问题

什么是EBITDA？

EBITDA即息税折旧摊销前利润，是衡量企业经营盈利能力的核心指标。排除了利息、税收、折旧和摊销等非经营性因素，便于不同企业间横向比较。

EBITDA和净利润有什么区别？

净利润 = 收入 - 所有费用。EBITDA = 净利润 + 利息 + 所得税 + 折旧 + 摊销。EBITDA排除了资本结构和税收政策的影响。

EV/EBITDA是什么？

EV/EBITDA是企业价值与EBITDA的比值。一般10-15倍为合理区间。高增长企业可达20-30倍。
