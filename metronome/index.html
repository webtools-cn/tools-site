📖 使用说明

1. 设置速度：拖动滑块或点击下方预设按钮，把 BPM 调到目标值。BPM（每分钟拍数）范围为 30–300，覆盖从 Largo（广板）到 Presto（急板）的全部区间。也可以直接用键盘 ↑/→ 加速、↓/← 减速。

2. 选择拍号：2/4 常用于进行曲，3/4 是华尔兹的基础，4/4 是最通用的拍号，6/8 常见于流行和摇滚。切换后节拍圆点数量会随之变化。

3. 首拍重音：勾选“首拍重音”后，每个小节第 1 拍会用更高的音高发声并显示为红色，方便听清小节起点；取消勾选则所有拍子音高一致。

4. 选择音色：木鱼清脆、电子精准、滴答短促，可按个人习惯与练习环境选择。

5. 开始练习：点击“开始”或按空格键，节拍器开始发声，摆锤左右摆动，当前拍圆点同步高亮。再次点击或按空格键即可停止。

❓ 常见问题

在线节拍器支持哪些 BPM 范围？

本节拍器支持 30 到 300 BPM 的调节范围，覆盖从极慢板到急板的全部速度区间，可用滑块、预设按钮或键盘方向键调节。

节拍器的声音是从哪里来的？

所有声音都由浏览器 Web Audio API 实时合成，不加载任何音频文件，也不依赖外部库。首次点击开始后才创建音频上下文，以符合浏览器的自动播放策略。

支持哪些拍号和音色？

支持 2/4、3/4、4/4、6/8 四种拍号，以及木鱼、电子、滴答三种音色。首拍重音可以单独开关，打开时第 1 拍使用更高的音高并高亮显示。

有键盘快捷键吗？

有。按空格键开始或停止节拍器；按上/右方向键加速，下/左方向键减速；按住 Shift 再按方向键则以 5 BPM 为单位调节。

可以在手机上使用吗？

可以。本工具采用响应式设计，在手机和平板上均能正常显示和发声，建议练习时佩戴耳机以获得更清晰的听觉反馈。

节拍器会消耗大量电量吗？

不会。纯前端运行的节拍器仅用 Web Audio API 生成简单波形，CPU 占用极低，对电池续航几乎没有影响。

如何保存我喜欢的速度设置？

可以在地址栏中直接使用 URL 参数，例如 https://free-toolbase.com/metronome/?bpm=100&beats=4 ，把该地址加入书签即可快速回到常用设置。
