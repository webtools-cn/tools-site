隐私政策

最后更新：2026年7月12日

1. 我们的核心隐私原则

Free ToolBase 上的所有数据处理完全在你的浏览器中完成。我们不会将你输入工具的任何数据上传、存储或传输到任何服务器。你的文件、文本和计算结果永远不会离开你的设备。

2. 我们收集的信息

2.1 分析数据

我们使用 Google Analytics 来了解访客如何使用我们的网站。这会收集：

  • 访问的页面和停留时间
  • 来源网站或搜索引擎
  • 设备类型、浏览器和操作系统
  • 大致地理位置（国家/城市级别）

这些数据是匿名的，无法识别个人用户。

2.2 你输入到工具中的数据

我们不会收集你输入到工具中的任何数据。所有处理都在你的浏览器中使用 JavaScript 在客户端完成。没有任何数据被发送到我们的服务器或任何第三方服务器。

2.3 Cookie

我们使用以下 Cookie：

  • Google Analytics Cookie（_ga、_gid、_gat）——用于区分用户和跟踪页面浏览量。这些是由 Google Analytics 设置的第一方 Cookie。

除了分析所必需的 Cookie 外，我们不使用任何广告 Cookie 或跟踪 Cookie。

3. 第三方服务

3.1 Google Analytics

我们使用 Google Analytics 来分析网站流量。Google Analytics 通过 Cookie 收集数据，并根据 Google 隐私政策进行处理。你可以通过安装 Google Analytics 退出浏览器插件来退出。

3.2 Google AdSense

我们可能通过 Google AdSense 展示广告。Google 及其合作伙伴可能使用 Cookie 根据你之前访问我们网站或其他网站的记录来投放广告。你可以通过访问 Google 广告设置来退出个性化广告。

Google 使用广告 Cookie 使其及其合作伙伴能够根据你访问我们网站和/或互联网上其他网站的情况投放广告。你可以通过访问 Google 广告设置来退出个性化广告。

3.3 GitHub Pages

我们的网站托管在 GitHub Pages 上。GitHub 可能会作为其托管服务的一部分收集服务器日志。详情请参阅 GitHub 隐私声明。

4. 数据安全

由于所有工具处理都在你的浏览器中完成，你的数据安全得到了内在保障：

  • 使用工具时不会通过互联网传输任何数据
  • 我们网站的所有连接都使用 HTTPS 加密
  • 我们没有可能被攻破的数据库

5. 儿童隐私

我们的服务不面向 13 岁以下的儿童。我们不会故意收集 13 岁以下儿童的个人身份信息。如果你认为我们收集了 13 岁以下儿童的信息，请立即联系我们，我们将采取措施删除此类信息。

6. 你的权利

根据你所在的司法管辖区，你可能有权：

  • 访问我们持有的关于你的个人数据
  • 要求更正或删除你的数据
  • 反对处理你的数据
  • 要求数据可移植性

由于我们收集的数据极少（仅匿名分析数据），这些权利大多已自动满足。如有任何请求，请通过 dexshuang@google.com 联系我们。

7. 政策变更

我们可能会不时更新本隐私政策。我们将通过在本页面上发布新的隐私政策并更新"最后更新"日期来通知你任何变更。你在变更后继续使用本网站即表示接受更新后的政策。

8. 联系我们

如果你对本隐私政策有任何疑问，请通过以下方式联系我们：

📧 dexshuang@google.com

或者在我们的 GitHub 仓库上提交 Issue。
