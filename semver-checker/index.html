📖 什么是语义化版本？

语义化版本（Semantic Versioning，简称 Semver）是软件版本管理的标准规范。版本号格式为：

主版本.次版本.修订号
  • 主版本（MAJOR） — 不兼容的 API 变更（破坏性更新）
  • 次版本（MINOR） — 新增功能，向下兼容
  • 修订号（PATCH） — 问题修复，向下兼容

可选扩展：-alpha.1（预发布标签）和 +build.123（构建元数据）。

本工具帮助您验证任意版本号是否符合 semver 规范，并比较两个版本的大小——适用于依赖管理、CI/CD 流程和版本发布管理。

什么是语义化版本(semver)？

语义化版本（semver）是一种版本命名规范，格式为主版本.次版本.修订号。主版本号增加表示不兼容的API变更，次版本号增加表示新增向下兼容的功能，修订号增加表示向下兼容的问题修复。还可以附加预发布标签（如-alpha.1）和构建元数据（如+build.123）。

这个工具免费吗？

完全免费，无需注册，无需下载。所有解析和比较都在浏览器本地完成，您的版本字符串绝不会离开您的设备。

支持哪些semver格式？

支持完整的semver 2.0.0规范：主版本.次版本.修订号（如2.1.0），预发布标签（如2.1.0-alpha.1），构建元数据（如2.1.0+build.123），以及可选的v前缀（如v2.1.0）。
