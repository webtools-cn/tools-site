💡 什么是到期收益率(YTM)？

到期收益率(Yield to Maturity)是债券投资中最重要的指标之一。它表示如果你以当前市场价格买入债券并持有至到期，预期能获得的年化总回报率。YTM考虑了票面利息收入和买入价格与面值之间的差价。

💰 折价债券

市场价格低于面值时，YTM > 票面利率，因为你还能赚取价差收益。

📊 溢价债券

市场价格高于面值时，YTM < 票面利率，价差损失会拉低实际回报。

🎯 平价债券

市场价格等于面值时，YTM = 票面利率。

❓ 常见问题

YTM和当前收益率有什么区别？

当前收益率 = 年票息 / 市场价格，只考虑利息收入。YTM额外考虑了买入价格与面值的差价，是更全面的回报衡量指标。

YTM越高越好吗？

YTM越高通常意味着回报越高，但也可能反映更高的信用风险。折价较大的债券YTM较高，但可能面临违约风险。

这个计算器如何计算YTM？

使用迭代法(Newton-Raphson)求解现金流贴现方程，精确到0.0001%。

到期收益率计算器 (YTM)的计算逻辑

本工具的核心计算逻辑：

  • periods = Math.round(years * freq)
  • coupon = (faceValue * couponRate / 100) / freq
  • r = couponRate / 100 / freq
  • df = Math.pow(1+r, -t)
  • f = pv - marketPrice
  • rNew = r - f / dpv
