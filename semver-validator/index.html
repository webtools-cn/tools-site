📖 什么是 SemVer？

语义化版本（Semantic Versioning，简称 SemVer）是软件版本管理规范，格式为 MAJOR.MINOR.PATCH：

  • 主版本号 MAJOR：不兼容的 API 修改时递增
  • 次版本号 MINOR：向下兼容的功能新增时递增
  • 补丁版本号 PATCH：向下兼容的问题修复时递增
  • 预发布标签：可选，如 -alpha、-beta.1
  • 构建元数据：可选，如 +build.123

完整规范见 semver.org

❓ 常见问题

Q：如何判断版本号是否有效？

有效版本号必须符合 MAJOR.MINOR.PATCH 格式，MAJOR/MINOR/PATCH 为非负整数且不能有前导零。预发布标签以连字符开头，构建元数据以加号开头。

Q：版本比较的规则是什么？

先比较主版本号→次版本号→补丁版本号。有预发布标签的版本低于正式版本。比较预发布标签时，数字标识符按数值比较，字母标识符按字典序比较。

Q：支持哪些版本格式？

严格模式仅支持标准 MAJOR.MINOR.PATCH 格式。宽松模式额外支持 v1.0.0、1.0 和 1 等简化格式。
