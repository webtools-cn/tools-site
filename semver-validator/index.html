❓ 常见问题

什么是语义化版本（SemVer）？

语义化版本（Semantic Versioning）是一种版本号规范，格式为 MAJOR.MINOR.PATCH。当你做了不兼容的API修改时增加主版本号(MAJOR)，新增向下兼容的功能时增加次版本号(MINOR)，做向下兼容的问题修正时增加修订号(PATCH)。详见 semver.org。

预发布版本和构建元数据是什么？

预发布版本如 1.0.0-alpha.1，表示主版本之前的测试版。构建元数据如 1.0.0+build.2024，仅用于区分构建，不影响版本优先级。构建元数据在版本比较时会被忽略。

^ (caret) 和 ~ (tilde) 范围有什么区别？

^1.2.3 匹配 >=1.2.3 且 <2.0.0 的所有版本（允许minor和patch变更）。~1.2.3 匹配 >=1.2.3 且 <1.3.0 的所有版本（仅允许patch变更）。这是 npm package.json 中最常用的范围语法。

为什么 "v1.0.0" 不是有效的 SemVer？

SemVer 规范要求版本号必须是纯数字加点号，不允许 "v" 前缀。"v1.0.0" 是 Git tag 的常见写法，但不是合法的语义化版本号。如果你需要处理带 v 前缀的版本号，我们的工具会给出警告。
