油耗单位换算说明

油耗（燃料消耗量）是衡量车辆燃油经济性的重要指标，不同国家和地区使用不同的计量单位：

  • L/100km：中国、欧洲、澳洲常用，表示行驶100公里消耗的燃油升数，数值越低越省油。
  • MPG (US)：美国常用，1美制加仑=3.785升，数值越高越省油。
  • MPG (UK)：英国常用，1英制加仑=4.546升，同等油耗下数值比MPG(US)高约20%。
  • km/L：日本、印度等亚洲国家常用，表示每升燃油可行驶的公里数，数值越高越省油。

换算公式

  • MPG(US) = 235.215 / L/100km
  • MPG(UK) = 282.481 / L/100km
  • km/L = 100 / L/100km
  • MPG(UK) = MPG(US) × 1.2009

油耗单位换算器常见问题

L/100km和MPG有什么区别？▼
L/100km表示行驶100公里消耗的燃油升数，数值越低越省油；MPG表示每加仑燃油可行驶的英里数，数值越高越省油。两者呈反向关系：MPG = 235.215 / L/100km。因此L/100km越小，MPG越大，都代表更省油。
如何将L/100km转换为MPG？▼
使用公式：MPG(US) = 235.215 / L/100km，MPG(UK) = 282.481 / L/100km。例如8 L/100km ≈ 29.4 MPG(US) ≈ 35.3 MPG(UK)。只需将235.215或282.481除以L/100km的数值即可得到对应的MPG值。
美国MPG和英国MPG一样吗？▼
不一样。美国加仑（US gallon）约3.785升，英国加仑（Imperial gallon）约4.546升。由于英制加仑更大，同样的燃油量能跑更远，所以MPG(UK)数值比MPG(US)高约20%。换算关系：MPG(UK) = MPG(US) × 1.2009。
什么是km/L？▼
km/L表示每升燃油可行驶的公里数，是亚洲地区常用的油耗指标。与L/100km互为倒数关系：km/L = 100 / L/100km。数值越高越省油。例如8 L/100km = 12.5 km/L。
