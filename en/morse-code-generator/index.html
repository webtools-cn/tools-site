About This Tool

Morse code is a communication encoding method invented in the 19th century, representing letters and numbers through combinations of dots (.) and dashes (-). This tool supports bidirectional conversion between text and Morse code, covering A-Z, 0-9 and common punctuation. All conversion is done locally in your browser.
