📖 How to Use

• Enter the total tip amount for the shift (supports any currency).

• Add staff members by role. System auto-assigns fair weights — Server (5), Bartender (4), Runner/Kitchen (3), Host/Busser (2).

• Select "Custom" to manually set weight values (0.5-10).

• Click "Calculate" to distribute tips proportionally by weight, rounded to the nearest cent.

• All calculations are done locally in your browser — no data is ever uploaded.
