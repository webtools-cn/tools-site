Learn More

Function Calling is a technique that lets LLMs interact with external tools. OpenAI introduced Function Calling in June 2023, and Anthropic later added Tool Use. The formats differ: OpenAI uses the function and parameters fields, while Anthropic uses input_schema. In 2024-2026, MCP (Model Context Protocol) is becoming the standard for tool definitions, making tools work across platforms.
