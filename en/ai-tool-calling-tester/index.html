Learn More

Function Calling（函数调用）是LLM与外部Tools交互的核心机制。OpenAI于2023年6月推出Function Calling，Anthropic随后推出Tool Use。两者Format略有不同：OpenAI使用function和parameters字段，Anthropic使用input_schema。2024-2026年，MCP（Model Context Protocol）正在统一Tools定义标准，使Tools可以Cross-platform复用。

FAQ

什么是Function Calling？

Function Calling是LLM根据用户Input决定调用哪个函数、Extract什么Parameters的能力。LLM不直接执行函数，而是Back函数名和Parameters，由应用层执行。

OpenAI和AnthropicFormat有什么区别？

OpenAI使用function.parameters，Anthropic使用input_schema。Parameters结构基本相同，但包装方式不同。本Tools可一键切换两种Format。

如何定义好的ToolsSchema？

好的Schema需要：清晰的Tools名称和描述、明确的ParametersType和描述、合理的required字段、使用enum限制可选值。

模拟调用的Result准确吗？

模拟调用展示的是LLM可能Back的Format，实际Parameters由LLM根据用户消息Extract。模拟Result仅供参考FormatValidate。

数据会Upload服务器吗？

不会。所有SchemaGenerate和Validate完全在Browse器Local完成。
