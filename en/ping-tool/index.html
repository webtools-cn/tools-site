How to Use

1. 在输入框中填写目标域名或IPAddress（如 google.com 或 8.8.8.8).

2. 选择Packet Count（默认4次）和Timeout（默认2000ms).

5. 点击「Stop」可中途终止测试，「Reset」清空所有结果。

FAQ

What is Ping and what is it used for?

Ping是网络诊断Tools，用于测试本机与目标服务器之间的连通性。它通过SentICMP回显请求并等待响应，测量往返时间（延迟）和Loss。常用于：检测网站是否可达、判断网络故障、评估服务器响应速度。

Why is my ping so high?

High latency causes: physical distance (e.g., overseas servers), network congestion, server load, ISP routing issues. Domestic to overseas: 150-300ms is normal; domestic to domestic: typically <50ms.

What if packet loss is 100%?

Possible causes: target server disabled ICMP (common on cloud platforms), firewall blocking, DNS failure, complete network outage. Check domain spelling first, or verify via browser.

What's the difference between online and command-line Ping?

命令行Ping直接从你的电脑SentICMP包，在线Ping从Tools站服务器Sent。在线Ping适合在没有命令行环境（如手机）或需要从不同地理位置测试时使用。注意：本Tools通过Web Worker模拟Ping行为，适合快速连通性检查。
