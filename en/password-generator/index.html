📖 How to Use

Mode 1: Random Password

Select Password Length(4-128 chars) and character types. Check "Exclude Similar" to remove 0/O/1/l/I. Drag the slider to generate in real-time. You can also use the Custom Charset (e.g., Hex: 0123456789abcdef) for specific requirements.

Mode 2: Passphrase

3-10 random English words, e.g. correct-horse-battery-staple. Optional separator (hyphen/space/dot/underscore), capitalize, add number at end. Passphrases are easier to remember than random strings while remaining highly secure.

Mode 3: PIN Code

Numbers Only PIN Code, 4-16 digits. Supports plain, 4-digit space grouping, and 4-digit dash grouping. Ideal for bank PINs, security codes, and verification codes..

💡 Password Security Tips

Length First: Password length matters more than complexity..Use at least 12 characters; 16 is better..

Passphrase: A 5-word passphrase is more secure and easier to remember than 12 random characters..Entropy can reach 100+ bits..

Mix Characters: Combine uppercase, lowercase, numbers, and symbols to dramatically increase brute-force resistance..

Avoid Patterns: Don't use dictionary words, birthdays, phone numbers, or other guessable information.

Uniqueness: Use different passwords for each site — one breach shouldn't compromise everything.

Rotate Regularly: Rotate important passwords every 3-6 months and enable two-factor authentication (2FA).

❓ FAQ

Are generated passwords really secure?

Yes. This tool uses the browser's crypto.getRandomValues() for true randomness. All computation happens locally — passwords are never transmitted or stored on any server.

What is leak detection?

Click 🔍 to check against Have I Been Pwned via k-anonymity API. Only the first 5 SHA-1 hash characters are sent for querying — your full password never leaves your browser.

How is crack time calculated?

Based on password entropy and modern GPU clusters at 100 billion guesses/second. Higher entropy = longer crack time. A 16-char password with uppercase, lowercase, numbers, and symbols has ~100 bits — billions of years to brute-force.

Passphrase vs random password — which is better?

Passphrases (e.g., correct-horse-battery-staple) are easier to remember — 5 random words = 100+ bits. Random passwords are more compact but harder to remember. Use passphrases for manual entry, random passwords for password managers.

What does the password strength bar mean?

Based on entropy. Weak (red, <30 bits) → Medium (orange, 30-50) → Strong (yellow, 50-70) → Very Strong (green, >70). A 16-char password with all types is usually "Very Strong".

Why exclude similar characters?

Characters 0/O, 1/l/I are hard to distinguish in sans-serif fonts. Excluding them prevents manual entry errors.

Are exported password files secure?

All exports happen locally in your browser. Files download directly to your device — never touch any server. Encrypt exported files or import to a password manager, then delete the originals.

How does QR code sharing work?

Click 📱 to generate a QR code containing the password. Scan with your phone camera to transfer from desktop to mobile. QR codes are generated entirely in your browser — passwords are never uploaded.

What is the memorability score?

Each password shows a memorability rating: Easy (passphrases, numeric PINs), Medium (letters+numbers), Hard (random strings with symbols). Helps you balance security and memorability.
