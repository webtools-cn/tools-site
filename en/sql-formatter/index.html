📖 How to Use

Using the SQL Formatter

Paste your SQL code into the left input area, choose your formatting options, then click "Format" or "Minify". The result appears instantly on the right. You can copy or download the result.

Formatting Options Explained

  • Uppercase Keywords: Automatically converts SQL keywords (SELECT, FROM, WHERE, JOIN, INSERT, etc.) to uppercase for better readability.
  • Indent Spaces: Sets the number of spaces per indentation level (default: 2). Adjust to match your team's coding style.
  • Newline After Comma: Places each column name on its own line after SELECT, making it easier to scan and modify column lists.
  • Align AND/OR: Aligns AND/OR conditions in WHERE clauses to the same column, making logical relationships clear at a glance.

Minify Mode

Click "Minify" to compress SQL into a compact single-line format by removing all unnecessary whitespace and line breaks. This is ideal for embedding SQL into code strings or reducing transmission size. The minified SQL remains semantically identical and fully executable.

❓ FAQ

What does SQL formatting do?

SQL formatting expands compressed single-line SQL into a well-structured, properly indented format for easier reading, debugging, and code review. It can also compress verbose SQL into compact format to reduce transmission size.

Which SQL dialects are supported?

Supports MySQL, PostgreSQL, SQLite, Oracle, SQL Server, and other major SQL dialects. The tool recognizes common keywords across all dialects. Unrecognized keywords are preserved as-is without affecting the output.

Is my SQL uploaded to any server?

No, never. This tool is pure client-side. All formatting is done in your browser via JavaScript. Your SQL code never leaves your device — your privacy and business data are absolutely safe. You can confidently process SQL containing sensitive business logic.

Can it format nested subqueries?

Yes. The tool automatically detects nested subqueries (SELECT statements within parentheses) and indents each level progressively, making multi-level nesting clear at a glance. Arbitrary nesting depth is supported.

Will minified SQL still execute correctly?

Yes. Minification only removes unnecessary whitespace and line breaks — it does not change SQL semantics. The minified SQL is functionally identical to the original and will execute normally in any database. We recommend testing in a non-production environment first.

Can I copy or download the result?

Yes. After formatting or minifying, click "Copy Result" to copy to clipboard with one click, or click "Download .sql" to save the result as a .sql file locally for integration into your project.
