Frequently Asked Questions

What is a Canonical URL?

A Canonical URL tells search engines which URL is the primary version of a page, helping resolve duplicate content issues.

When should I use Canonical?

When the same content is accessible via multiple URLs (e.g., with/without www, HTTP/HTTPS, with parameters), set a Canonical pointing to the preferred version.
