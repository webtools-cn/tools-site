❓ FAQ
Does the sitemap comply with search engine standards?
Fully compliant with Google, Bing sitemap protocol (sitemaps.org). Includes loc, lastmod, changefreq, priority standard fields.
How many URLs are supported?
Up to 500 URLs per generation (single sitemap limit). For more URLs, generate in batches or use sitemap index files.
How to use after generation?
Download the XML file, upload to site root, then submit the sitemap URL in Google Search Console. Or copy the content directly to save.
