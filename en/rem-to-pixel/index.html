About REM and PX

REM (Root EM) is a CSS unit relative to the root element <html> font size. Browser default is 16px.

PX (Pixel) is the absolute pixel unit in CSS, representing a physical or logical screen pixel.

Formulas:

REM → PX: rem value × root font size = px value

PX → REM: px value ÷ root font size = rem value

Using REM helps maintain proportional consistency across different devices and font settings — a recommended practice in modern responsive design.
