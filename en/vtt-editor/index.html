❓ FAQ

What is the WebVTT format?

WebVTT (Web Video Text Tracks) is the W3C standard format for web video subtitles, designed for HTML5 <video> elements. It supports styling (font color, position, alignment) and is the preferred format for modern web video subtitles.

What's the difference between VTT and SRT?

VTT is the web standard supporting CSS styling, position control, and vertical text. SRT is a traditional format with wider compatibility but simpler features. VTT files start with "WEBVTT" and use dots for milliseconds; SRT uses commas. This tool supports VTT editing and SRT export.

How do I adjust subtitle timing?

Enter the offset in seconds (negative to shift earlier, positive to shift later) and click "Adjust Timeline". Scale factor adjusts speed (1.0 = original, >1 faster, <1 slower).

Is my subtitle file safe?

Completely safe. All editing is done locally in your browser. Your files are never uploaded to any server. Data is cleared when you close the page.

What styles does VTT support?

WebVTT supports color, background-color, font-size, alignment, position/line, and other CSS properties. This tool edits plain text content; styles can be added manually after export.
