About Curtain Length Calculator

Curtain Length Calculator is a free online tool. Calculate curtain fabric length based on window size and style, supports floor-length/sill/Roman Works on mobile and desktop, all calculations run locally in your browser for privacy.

Curtain Length Calculator in 3 steps

  1. Enter window height and width (cm)
  2. Select curtain style (floor / sill / standard)
  3. Click "Calculate" to see required fabric size

Is this tool accurate?

Results are computed with standard, industry-accepted formulas for Window height and Window width calculations.

Do I need to download anything?

No, it runs entirely in your browser. No downloads needed.
