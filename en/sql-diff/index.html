❓ FAQ

Is SQL Diff Tool free?

Yes, completely free. All processing happens locally in your browser with no registration required.

Which SQL dialects are supported?

All SQL dialects are supported including MySQL, PostgreSQL, SQLite, and SQL Server. The tool compares text differences line by line and does not depend on any specific SQL dialect.

Is my data safe?

Absolutely. All processing happens locally in your browser. SQL data is never uploaded to any server.

How do I read the diff results?

Green background indicates added lines, red background indicates deleted lines, and gray background indicates unchanged lines.
