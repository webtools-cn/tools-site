Speech Timer - Free Online Speaking Time Calculator

The Speech Timer is a free online tool that helps speakers, teachers, students, and trainers accurately estimate speech duration. Simply paste your speech text, choose a speed mode, and the tool calculates the estimated speaking time. Section timing lets you see each segment's duration by separating paragraphs with blank lines.

Key Features

  • Real-time estimation: See speaking time instantly as you type
  • Three speed modes: Slow (100 wpm), Normal (150 wpm), Fast (200 wpm)
  • Custom speed: Enter any words-per-minute rate from 50 to 400
  • Target time comparison: Set a goal and see if you're on track
  • Section timing: Separate sections with blank lines for per-part timing
  • Privacy-first: All processing is local, speech text is never uploaded

FAQ

How do I use the Speech Timer?

Paste your speech text into the input box, select a speaking speed (Slow 100 wpm, Normal 150 wpm, Fast 200 wpm), and the tool automatically calculates estimated speaking time. Set a target time to compare actual vs. expected duration.

Which speed mode should I choose?

Slow (100 wpm) is ideal for formal speeches and teaching. Normal (150 wpm) suits most presentation scenarios. Fast (200 wpm) works for TED-style rapid presentations. You can also enter a custom words-per-minute rate.

How does section timing work?

Separate paragraphs/chapters with blank lines, and the tool calculates estimated duration for each section. Total time is the sum of all section durations.

Is my data secure?

Everything runs locally: Custom Speed and other values are processed on your device, never sent to a server. Speech text is never uploaded to any server. Data is cleared when you close the page.
