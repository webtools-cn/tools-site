FAQ

Where is my data stored?

All data is stored in your browser's localStorage. Nothing is uploaded to any server. Clearing your browser cache will delete data, so please export CSV backups regularly.

Can I track multiple projects at once?

Only one project can run at a time. Starting a new project timer will automatically pause any currently running project.

How do I export my data?

Click "Export CSV" to download a CSV file with all project time records, which you can open in Excel or Google Sheets.
