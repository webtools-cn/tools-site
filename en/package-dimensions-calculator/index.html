About Package Dimensional Weight Calculator

Package Dimensional Weight Calculator is a free online tool. Calculate dimensional weight for shipping, supporting SF/ZTO/STO/DHL/UPS/FedEx standards Works on mobile and desktop, all calculations run locally in your browser for privacy.

How to Use

  1. Enter package length, width, and height (cm)
  2. Enter actual weight (kg)
  3. Click "Calculate" to see dimensional and chargeable weight
