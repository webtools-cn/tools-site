FAQ

What is the recommended line height?

For body text, a line height of 1.5-1.8 is generally recommended, while headings typically use 1.2-1.4. Line heights below 1.2 make text feel cramped and hard to read, while values above 2.0 spread the text out too much.

Should I use unitless line height?

Unitless values are the recommended approach because the line height scales proportionally with the font size. px values do not scale, which can cause text to overlap when the font size changes.
