🔌 Port Scanner

Check port status of target hosts · Common port presets and custom range support

Enter target host address, select port range or use common port presets, and check port status. Note: browser limitations restrict detection to HTTP/HTTPS ports.

Frequently Asked Questions

Is this tool free to use?
Yes, 100% free with no hidden charges and no usage limits.
How does port detection work?
Due to browser security restrictions, this tool uses fetch requests to detect HTTP/HTTPS port responses. Non-HTTP port detection is limited.
What ports are supported?
Common HTTP ports (80/443/8080/8443) and WebSocket ports. Built-in 30+ common port presets.
How accurate are the results?
For HTTP/HTTPS ports, results are accurate. Non-web ports may show unknown status due to browser CORS policies.
Can I scan any host?
Limited by browser same-origin and CORS policies. Only hosts that allow cross-origin access can be checked. Local network hosts are usually detectable.
