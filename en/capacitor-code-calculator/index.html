💡 Capacitor Code Guide

Ceramic capacitors use a 3-digit code. First two digits are significant figures, third is the multiplier (power of 10), in pF.

Decode Rules

  • Code = XY × 10^Z pF
  • Example: 104 = 10 × 10^4 = 100,000 pF = 100 nF = 0.1 μF
  • Example: 472 = 47 × 10^2 = 4,700 pF = 4.7 nF
  • Code "0" or "000" = 0pF (jumper)

Common Code Reference

  • 101 = 100pF | 102 = 1nF | 103 = 10nF (0.01μF)
  • 104 = 100nF (0.1μF) | 105 = 1μF
  • 221 = 220pF | 471 = 470pF
  • 222 = 2.2nF | 472 = 4.7nF | 682 = 6.8nF
  • 223 = 22nF | 473 = 47nF | 683 = 68nF

Tolerance Letters

  • J = ±5% (most common) | K = ±10% | M = ±20%
  • F = ±1% | G = ±2%
  • B/C/D = Tight tolerance (RF use)
