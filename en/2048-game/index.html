About 2048 Game

2048 is a classic number puzzle game created by Gabriele Cirulli in 2014. Use arrow keys or touch swipe to slide tiles. When two tiles with the same number collide, they merge into one with double the value. The goal is to create a 2048 tile!

How to Play

  • Use arrow keys ↑ ↓ ← → to move tiles
  • Touch swipe supported on mobile devices
  • Click "Undo" to revert the last move
  • Identical numbers merge into double value
  • Game ends when the board is full with no valid moves

How to play 2048 Game?

The game starts automatically when you open the page with two tiles already on the board. Use arrow keys (↑↓←→) or touch swipe to move tiles. When two tiles with the same number collide, they merge into one with double the value. A new tile (2 or 4) appears after each move. You win when you create a 2048 tile!
