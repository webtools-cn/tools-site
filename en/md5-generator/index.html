Is MD5 still secure? When can I use it?

Defined by RFC 1321 (1992), MD5 outputs a 128-bit hash value. MD5 collision attacks were demonstrated in 2004, so MD5 is not recommended for security use (password storage, digital signatures, certificate verification). It remains acceptable for file deduplication, download integrity checks, and cache key generation in non-security contexts. For security, use SHA-256 or SHA-3.
