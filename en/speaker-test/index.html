❓ FAQ
How to test speakers?
Click left/right channel buttons to verify each channel works. Frequency sweep helps detect distortion or crackling at different frequencies.
Do I need to install software?
No! Uses the browser Web Audio API to generate test tones directly. No installation or plugins required.
Why can't I hear anything?
Check: 1) Device volume is on; 2) Not in silent mode; 3) Browser isn't muted by the system. Some browsers require a click before playing audio.
