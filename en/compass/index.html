Frequently Asked Questions

What permissions does the compass need?

Using the real orientation sensor requires HTTPS and device orientation permission. If unavailable, you can manually rotate the compass dial.

How accurate is it?

It uses the device's magnetometer/gyroscope data, typically accurate within 5 degrees for everyday direction finding.

Does it work on all devices?

Modern smartphones support orientation sensors. Desktop browsers usually can't obtain direction data — use manual mode instead.

The Online Compass is a free direction-finding tool that works directly in your browser — no installation required.
