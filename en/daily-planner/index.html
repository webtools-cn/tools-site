📋 Daily Planner

💡 Tips

  • Enter tasks for each time slot
  • Click the checkbox to mark tasks as done
  • Click ✕ to delete a task
  • Use the date picker to switch between days
  • Data is stored in your browser's local storage

📖 Frequently Asked Questions

Where is my plan data saved?

All plan data is saved locally on your device using the browser's localStorage API. Data persists after closing the page or restarting your browser. However, clearing browser cache or using private/incognito mode may cause data loss. Regular export backup is recommended.

Can I plan for multiple days?

This tool focuses on daily planning, showing today's plan by default. You can switch to different dates using the date picker and set plans for each day independently. Each day's plan is saved separately. For cross-day or long-term task management, use dedicated project management tools.

Will my plan data sync across devices?

Currently, data is only saved in the current browser's local storage and does NOT automatically sync to other devices. For cross-device use, export your plan data and import it on another device's browser. Cloud sync may be considered in future versions.

How do I recover deleted plans?

This tool does not currently support undo for deletions. Once deleted, data is permanently lost (unless you have a backup). Make sure before deleting tasks. Regular backup of your plan data is recommended.
