📖 CSS Anchor Positioning

What is CSS Anchor Positioning?

CSS Anchor Positioning is a new W3C specification that lets you position an element relative to another element (the anchor) without JavaScript. It is ideal for tooltips, popovers, dropdowns and other components.

Key Properties

  • anchor-name — marks an element as an anchor, e.g. anchor-name: --my-anchor
  • position-anchor — references the anchor, e.g. position-anchor: --my-anchor
  • position-area — sets the position area, e.g. position-area: top
  • position-try-fallbacks — defines fallback positioning
  • anchor() — function that references the anchor's edge position

Use Cases

  1. Tooltip — show hints near a trigger element
  2. Popover — show content below a trigger button
  3. Dropdown — align a list of options to an input
  4. Date picker — show a calendar below an input
  5. Notifications — display messages anchored to elements

📖 FAQ

What is the difference between anchor positioning and absolute positioning?

Absolute positioning places an element relative to its containing block, while anchor positioning places it relative to a specific anchor element. Anchor positioning keeps the positioned element attached to the anchor even when the anchor moves.
