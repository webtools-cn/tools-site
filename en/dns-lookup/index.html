How to Use the DNS Lookup

Perform a DNS lookup in three steps:

  1. Enter Your Domain
    Type the domain you want to check, e.g. example.com. You can also press Enter to start the lookup.
  2. Choose the Record Type
    Select from A, AAAA, CNAME, MX, NS, TXT, SOA, SRV or ALL. Optionally pick a DNS server (Cloudflare or Google) that handles the query.
  3. View and Copy the Results
    Click Lookup to instantly see records with type, name, value and TTL. Use the Copy Result button to save the output. Queries run over DNS-over-HTTPS and are never stored.
