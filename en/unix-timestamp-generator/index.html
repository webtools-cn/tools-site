关于Unix Timestamp

Definition

Unix Timestamp（Unix Epoch）是自1970年1月1日 00:00:00 UTC 以来经过的秒数，不包含闰秒。它是Calculate机系统中表示时间的标准方式。

Common Programming Examples

  • JavaScript: Date.now() → 毫秒时间戳；new Date(ts*1000) → 日期
  • Python: time.time() → 秒；datetime.fromtimestamp(ts)
  • Shell: date +%s → 秒；date -d @1700000000

Important Timestamps

  • 0 → 1970-01-01 00:00:00 UTC（Unix Epoch）
  • 1000000000 → 2001-09-09 01:46:40 UTC
  • 2000000000 → 2033-05-18 03:33:20 UTC
  • 2147483647 → 2038-01-19 03:14:07 UTC（32-bit overflow）
