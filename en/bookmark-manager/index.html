📂 My Bookmarks

How to Use

Add: Enter a title and URL, select a category, then click Add. All data is saved in your browser's local storage (localStorage) and is never uploaded to a server.

Search and Filter: Use the category filter or type a keyword in the search box to quickly find bookmarks. Click a title to open the link directly, click "Edit" to modify the info, click "Delete" to remove it.

Backup: Click Export to download a JSON backup. Click Import to restore from a previously exported JSON file. Imports are merged with existing data.

Privacy: All data is stored only in your browser. Data persists after closing the page. Clearing browser cache or using incognito mode may cause data loss.
