🗺️ Sitemap Checker

Enter a website URL to automatically detect and validate its sitemap.xml

How to Use

Enter the full URL of the target website. The tool will automatically try common sitemap paths (e.g. /sitemap.xml, /sitemap_index.xml) and check if the XML is valid while listing all included page URLs.

Note: Due to browser CORS restrictions, sitemap content can only be fetched if the target site allows cross-origin access.
