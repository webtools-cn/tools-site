Grid Image Splitter - Free Online Photo Grid Cutter

The Grid Image Splitter is a free online tool that slices any image into equal grid tiles. Perfect for Instagram grid layouts, WeChat moments, photo collage design, and social media posting. Choose from 2x2 to 6x6 grid sizes, output in PNG/JPG/WebP format. All processing happens locally in your browser — your images never leave your device.

Key Features

  • Custom grid sizes: 2×2 to 6×6
  • Multiple output formats: PNG lossless, JPG compressed, WebP recommended
  • Bulk download: Download individually or as ZIP
  • Live preview: See the split result instantly
  • Privacy safe: All processing done locally, no uploads
  • 100% free: No registration needed, unlimited use

FAQ

What image formats are supported?

JPG, PNG, WEBP, GIF, BMP and all common image formats are supported. Output can be PNG, JPG, or WebP.

Will the image quality decrease after splitting?

No. Splitting only divides the original image into multiple tiles at original resolution. PNG output is lossless.

Can I customize the grid size?

Yes. Choose from 2x2 to 6x6 grid, not just the standard 3x3 grid.

Are my images uploaded to a server?

No. All processing is done locally in your browser using HTML5 Canvas. Your images never leave your device.

How do I download all tiles at once?

Click "Download All Slices" to save each tile individually, or use "Download as ZIP" for a single compressed file with all slices.
