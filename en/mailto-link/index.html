📖 FAQ

What is a mailto link?

A mailto link is an HTML hyperlink in the format mailto:email@example.com?subject=Hello&body=Message. Clicking it opens the user's default email client with pre-filled fields.

What parameters are supported?

Supports to (recipient), cc (carbon copy), bcc (blind carbon copy), subject, and body. Multiple recipients separated by commas.

Why doesn't the link work?

Mailto requires a configured default email client. Set your default mail app in system settings (Outlook / Apple Mail / Gmail).

Does it work on mobile?

Yes. Mobile browsers support the mailto protocol. Tapping a mailto link opens the device's email app.
