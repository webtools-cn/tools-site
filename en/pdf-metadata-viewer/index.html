About PDF Metadata

What is PDF Metadata?

PDF元数据是嵌入在PDF文件中的描述性信息，包括文档属性、创建历史、SecureSettings等。这些信息在文件创建时由Generate软件自动Add，可以帮助了解文档的来源和属性。

Common Metadata Fields

  • Title - 文档Title
  • Author - Author名称
  • Subject - 文档Subject
  • Keywords - Keywords
  • Creator - 创建该PDF的软件
  • Producer - PDFGenerate引擎
  • CreationDate - Creation Date
  • ModDate - 最后Modification Date
  • Pages - Pages
  • PDF Version - PDFFormat版本
  • Encrypted - Encrypted
  • File Size - File Size
