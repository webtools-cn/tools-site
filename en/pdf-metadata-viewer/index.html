About PDF Metadata

What is PDF Metadata?

PDF metadata is the descriptive property information stored within a PDF file, including text file attributes, creation details, security settings, and more. This information is automatically added when a file is created and can reveal the source and attributes of the document.

Common Metadata Fields

  • Title - Document title
  • Author - Author name
  • Subject - Document subject
  • Keywords - Keywords
  • Creator - Application that created the PDF
  • Producer - PDF generator
  • CreationDate - Creation date
  • ModDate - Last modification date
  • Pages - Number of pages
  • PDF Version - PDF format version
  • Encrypted - Encryption status
  • File Size - File size

Privacy Notice

PDF parsing is completed entirely within your browser. File content is never uploaded to any server. After parsing, data is protected in your browser's memory.
