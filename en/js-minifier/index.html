Free online JavaScript minifier that removes comments, whitespace, and newlines to reduce file size.

💡 How to Use

  • Paste your JavaScript code into the input area
  • Choose compression mode (Standard/Aggressive)
  • Click "Minify JS" to get the compressed result
  • Click "Copy" to copy the minified code
  • Click "Download" to save as .min.js file

⚙️ Compression Strategy

  • Remove all comments (// and /* */)
  • Remove unnecessary whitespace and newlines
  • Shorten variable names (aggressive mode)
  • Remove unnecessary semicolons and brackets
  • Simplify conditional expressions
  • Use shorter syntax sugar

🔒 Privacy

  • Everything runs locally: Mode and Preserve license com are processed on your device, never sent to a server
  • Your JS code never leaves your device
  • No registration required
