FAQ

What is device pixel ratio?

DPR is the ratio of physical pixels to CSS pixels. Retina screens typically have DPR=2, some high-end phones reach 3.

What's the difference between resolution and viewport?

Screen resolution is physical pixels (e.g., 1920×1080), viewport is the browser's visible area (minus taskbars, bookmarks), usually smaller.

Why check this info?

Frontend developers need screen parameters for responsive design; designers need target user device characteristics; monitor buyers reference it.
