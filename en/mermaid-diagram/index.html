Mermaid Syntax Quick Reference

Flowchart (flowchart)

  • flowchart TD - Top to bottom; LR - Left to right
  • A[rectangle] --> B(rounded) --> C{diamond}
  • Connectors: --> solid, -.-> dotted, ==> thick

Sequence Diagram (sequenceDiagram)

  • Alice->>Bob: message - solid head
  • Alice-->>Bob: message - dotted head

Gantt Chart (gantt)

  • dateFormat YYYY-MM-DD set date format
  • section phase separate sections
