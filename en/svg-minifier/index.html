📖 How SVG Minification Works

🔧 Minification Rules

  • Remove comments — Deletes all <!-- ... --> blocks
  • Collapse whitespace — Strips extra spaces, newlines, and indentation
  • Remove metadata — Deletes <metadata>, <title>, <desc>, and editor-specific namespace attributes
  • Trim decimals — Rounds path coordinates to 3 decimal places (e.g. 12.345678 → 12.346)
  • Remove defaults — Drops attributes with default values (e.g. version="1.1", fill="black")
  • Remove empty attrs — Strips attributes with empty values (e.g. class="", data-name="")

💡 Tips

Always keep a backup of your original SVG. This tool is ideal for final optimization before deploying to production. Icon-sized SVGs benefit most — often achieving 50-70% reduction.
