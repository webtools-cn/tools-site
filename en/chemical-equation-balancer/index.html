💡 How to Use

  • Use = or → to separate reactants and products
  • Separate multiple substances with +
  • Supports parentheses in formulas, e.g., Ca(OH)₂, Al₂(SO₄)₃
  • Supports ionic equations with + and - charge notation, e.g., Fe³⁺ as Fe+3
  • Use standard subscripts: glucose = C6H12O6
  • Balancing uses linear algebra method for mathematical precision

🔬 Common Reaction Types

  • Synthesis: A + B → AB (e.g., H₂ + O₂ → H₂O)
  • Decomposition: AB → A + B (e.g., CaCO₃ → CaO + CO₂)
  • Single Replacement: A + BC → AC + B (e.g., Fe + CuSO₄ → FeSO₄ + Cu)
  • Double Replacement: AB + CD → AD + CB (e.g., NaCl + AgNO₃ → AgCl + NaNO₃)
  • Redox: Electron transfer reactions (e.g., KMnO₄ + HCl)
  • Acid-Base Neutralization: Acid + Base → Salt + Water (e.g., HCl + NaOH → NaCl + H₂O)
