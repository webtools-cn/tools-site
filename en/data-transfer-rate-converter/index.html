Conversion Formula

Using bits per second (bps) as the base unit:

base = input × unit factor

result = base ÷ target unit factor

Factors: bps=1, Kbps=1000, Mbps=1e6, Gbps=1e9, B/s=8, KB/s=8000, MB/s=8e6, GB/s=8e9.

Frequently Asked Questions

Why is my 100Mbps connection only ~12.5 MB/s?

ISPs measure bandwidth in bits, while download tools report Bytes. Since 1 Byte = 8 bits, 100Mbps ÷ 8 = 12.5 MB/s, the theoretical maximum (real-world is slightly lower).

What is the relation between bps and B/s?

bps means bits per second, B/s means bytes per second. The relation is 1 B/s = 8 bps. Bandwidth uses lowercase b (bit); download/storage speed uses uppercase B (Byte).

Is K in Kbps 1000 or 1024?

Data transfer rates use SI decimal prefixes: K=1000, M=1,000,000, G=1,000,000,000. This differs from data storage (KiB=1024) — don't confuse them.
