❓ What is SemVer?

SemVer Format

Semantic Versioning uses the MAJOR.MINOR.PATCH format, e.g. 2.1.3. Increment MAJOR for incompatible API changes, MINOR for backward-compatible new features, and PATCH for backward-compatible bug fixes. Pre-release: 1.0.0-alpha.1. Build metadata: 1.0.0+build.abc. This tool is fully compliant with SemVer 2.0.

Valid Examples

✓ 1.0.0 | ✓ 0.1.0 | ✓ 2.1.3-beta.1 | ✓ 3.0.0-rc.2+build.789

✗ 1.0 | ✗ v1.0.0 | ✗ 1.0.0.0 | ✗ 01.1.1

Comparison Rules

Compare MAJOR → MINOR → PATCH. Pre-release versions have lower precedence than normal versions. Dot-separated pre-release identifiers are compared: numeric by value, alphabetical by ASCII order.
