📖 What is Semantic Versioning?

Semantic Versioning (semver) is the standard way to version software. A version number looks like:

MAJOR.MINOR.PATCH
  • MAJOR — Incompatible API changes (breaking changes)
  • MINOR — New features, backward-compatible
  • PATCH — Bug fixes, backward-compatible

Optional extensions: -alpha.1 (pre-release) and +build.123 (build metadata).

This tool helps you validate any version string against the semver spec and compare two versions to determine which is newer — useful for dependency management, CI/CD pipelines, and release workflows.

What is semantic versioning (semver)?

Semantic versioning (semver) is a versioning scheme that uses three numbers: MAJOR.MINOR.PATCH. MAJOR increases for incompatible API changes, MINOR for backward-compatible new features, and PATCH for backward-compatible bug fixes. Pre-release tags (like -alpha.1) and build metadata (+20240101) can also be appended.

Is this semver checker free?

Yes, completely free. No registration, no download required. All parsing and comparison runs locally in your browser — your version strings never leave your device.

What semver formats are supported?

We support the full semver 2.0.0 spec: MAJOR.MINOR.PATCH (e.g. 2.1.0), pre-release tags (e.g. 2.1.0-alpha.1), build metadata (e.g. 2.1.0+build.123), and optional 'v' prefix (e.g. v2.1.0).
