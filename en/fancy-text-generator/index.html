❓ Frequently asked questions

How does a fancy text generator work?

It does not change your font. Instead, it swaps ordinary letters and digits for visually similar Unicode characters (mathematical alphabet symbols, circled letters, fullwidth forms and so on), so the result can be pasted into any text field.

Can I convert Chinese or other non-Latin text?

The fancy styles rely on Unicode characters reserved for Latin letters and digits, so Chinese characters are left unchanged. You can still apply the styles to the Latin and numeric parts of a nickname.

Why do a few letters look different from the rest?

Some letters only exist as compatibility characters in Unicode (for example the script lowercase e is ℯ). This tool maps those exceptions individually so every letter has a matching styled character.

The text shows as boxes on my device. Why?

A small number of older devices or fonts may lack certain uncommon characters and display a placeholder box. Most modern phones and computers include them. If you hit this, simply choose a different style.

Is the text I type uploaded anywhere?

No. The conversion happens entirely in your browser. Nothing you type is sent to a server or stored.

Can I use these fonts in game nicknames?

Usually yes, but some games filter or restrict non-standard characters. Test the result in the game first to make sure the nickname can be saved.
