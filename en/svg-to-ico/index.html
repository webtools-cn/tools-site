FAQ

Do I need to upload my file to a server?

No. All processing happens in your browser. Your file never leaves your device, ensuring complete privacy.

What SVG files are supported?

All standard SVG files (SVG 1.1 and SVG 2.0) are supported, including inline styles and paths.

Can ICO files contain multiple sizes?

This tool generates single-size ICO files. For multi-size ICOs (e.g. for favicons), convert multiple times and combine with other tools.

What are ICO files used for?

ICO files are primarily used for website favicons, Windows application icons, and folder icons.

What's the maximum SVG size?

Input files up to 10MB, output up to 512×512 pixels.
