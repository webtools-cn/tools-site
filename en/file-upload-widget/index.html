Frequently Asked Questions

Are files uploaded to a server?

No. All file processing happens locally in your browser. Files are never uploaded to any server.

Which file types are supported?

Images (jpg/png/gif/webp/svg), documents (pdf/doc/txt), code files, and other common formats are supported. Allowed file types can be customized.
