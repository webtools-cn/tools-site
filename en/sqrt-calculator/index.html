Square Root Explained

The square root of a number is its second root. For example, the square root of 16 is 4 because 4² = 16. Mathematically written as √16 = 4.

FAQ

What is the square root of 16?

√16 = 4, because 4² = 16. 16 is a perfect square.

What is √2 approximately?

√2 ≈ 1.4142135624. It's an irrational number with infinite non-repeating decimals. When your calculator shows 1.414, that's rounded.

Can you take the square root of a negative number?

Not in real numbers. But in complex numbers, √(-1) = i (the imaginary unit). This calculator only supports non-negative real numbers.

What's the difference between square root and cube root?

Square root asks 'what number squared equals n' (√n), while cube root asks 'what number cubed equals n' (∛n). For example, √64 = 8 but ∛64 = 4 (since 4³ = 64).
