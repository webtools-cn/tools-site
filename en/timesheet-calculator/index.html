❓ FAQ

How does the timesheet calculator work?

Total hours = End time - Start time - Lunch break. For example, 9:00 AM to 6:00 PM with 12:00-1:00 lunch = 9h - 1h = 8h. Overtime = actual hours - standard hours.

How is overtime calculated?

Overtime = Actual hours - Standard hours. If actual hours exceed the standard (default 8 hours/day), the excess is overtime. Use with the Hourly Rate Calculator to compute overtime pay.
