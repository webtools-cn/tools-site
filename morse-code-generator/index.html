关于此工具

摩尔斯电码是19世纪发明的一种通信编码，通过点(.)和划(-)的不同组合表示字母和数字。本工具支持文字与摩尔斯电码的双向转换，支持A-Z、0-9和常用标点符号。所有转换在浏览器本地完成。
