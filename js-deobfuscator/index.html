📖 什么是JS反混淆？

JS反混淆（JavaScript Deobfuscation）是将经过混淆处理的JavaScript代码还原为人类可读格式的过程。混淆通常用于保护代码知识产权或减小文件体积，但也会让代码难以阅读和调试。

本工具支持的混淆模式

  • 代码压缩/最小化：移除空格、换行，缩短变量名（如 var a=1,b=2;）
  • 十六进制字符串：如 "\\x48\\x65\\x6c\\x6c\\x6f" → "Hello"
  • Unicode转义：如 "\\u0048\\u0065\\u006c\\u006c\\u006f" → "Hello"
  • 数组引用混淆：字符串存储在数组中通过索引引用（如 _0x1234("0x1") 模式）
  • 表达式简化：如 !![] → true，+[] → 0

常见应用场景

  • 安全分析：分析可疑JavaScript代码，检查是否有恶意行为
  • 逆向工程：理解第三方混淆代码的实现逻辑
  • 代码审查：将压缩依赖库还原为可读格式便于审查
  • 学习研究：学习混淆技术和防护机制

❓ 常见问题

反混淆和美化有什么区别？

美化（Beautify）只恢复缩进和格式；反混淆还会解码转义字符串、还原变量名、简化表达式，将代码还原得更接近原始形态。

我的代码会上传到服务器吗？

不会。所有处理都在你的浏览器本地完成，代码绝不会离开你的设备。你甚至可以断开网络后继续使用。

能100%还原原始代码吗？

不能。严重混淆的代码（如商业混淆器、obfuscator.io的强混淆）中，原始变量名和注释已经永久丢失。本工具能恢复结构和可读性，但无法恢复已删除的信息。

支持哪些混淆器？

本工具可处理常见的混淆技术：UglifyJS/Terser压缩、简单的obfuscator.io输出、十六进制/Unicode字符串编码、JavaScript Obfuscator的部分模式等。
