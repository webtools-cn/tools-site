常见问题

钢筋计算器怎么用？

输入混凝土板的长宽尺寸，选择钢筋规格和间距，设置边缘距离，点击计算即可得到每方向钢筋数量、总长度、总重量和预估成本。还支持搭接长度和单位切换。

钢筋间距怎么确定？

常见钢筋间距为150mm、200mm、250mm、300mm。板厚100-150mm通常用200mm间距，板厚150-200mm可用150mm间距。具体需根据结构设计要求确定。

钢筋搭接长度是多少？

搭接长度通常为钢筋直径的40倍（40d）。例如HRB400钢筋直径12mm，搭接长度约480mm。实际工程中需根据混凝土强度等级和钢筋类型按规范取值。

计算结果准确吗？

本计算器按理论公式计算，结果为估算值。实际用量需考虑损耗、搭接、弯钩等因素，建议多预留5-10%的余量。重要工程请以结构设计师的计算为准。

如何使用钢筋计算器

  1. 输入板尺寸
    输入混凝土板的长度、宽度和厚度。可切换公制或英制单位。
  2. 选择钢筋规格和间距
    从下拉菜单选择钢筋直径（HPB300/HRB400系列），设置钢筋间距和边缘保护层距离。
  3. 设置搭接和成本参数
    输入搭接长度（默认40d）、钢筋单价，选择单层或双层网格。
  4. 查看计算结果
    点击计算按钮，立即获得钢筋数量、总长度、总重量、含损耗重量和预估成本，并查看SVG布局图。

钢筋用量计算公式

纵向钢筋数量 = floor((板宽 - 2×边缘距离) / 间距) + 1

横向钢筋数量 = floor((板长 - 2×边缘距离) / 间距) + 1

单根纵向钢筋长度 = 板长 - 2×边缘距离 + 搭接长度

单根横向钢筋长度 = 板宽 - 2×边缘距离 + 搭接长度

钢筋总重量 = 总长度 × 单位长度重量（kg/m）

单位长度重量按公式 W = 0.00617 × d²（d为直径mm）计算，结果为kg/m。
