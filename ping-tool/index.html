使用教程

1. 在输入框中填写目标域名或IP地址（如 google.com 或 8.8.8.8）。

2. 选择发包次数（默认4次）和超时时间（默认2000ms）。

3. 点击「开始Ping」按钮，实时查看每次发包的延迟时间。

4. 测试完成后自动显示统计结果：最小/最大/平均延迟、丢包率。

5. 点击「停止」可中途终止测试，「重置」清空所有结果。

常见问题 FAQ

Ping是什么？有什么用？

Ping是网络诊断工具，用于测试本机与目标服务器之间的连通性。它通过发送ICMP回显请求并等待响应，测量往返时间（延迟）和丢包率。常用于：检测网站是否可达、判断网络故障、评估服务器响应速度。

为什么Ping值很高？

延迟高可能原因：物理距离远（如访问海外服务器）、网络拥堵、目标服务器负载高、ISP路由问题。国内访问海外通常在150-300ms属正常范围，国内互访一般<50ms。

丢包率100%怎么办？

可能原因：目标服务器禁用了ICMP协议（如某些云服务商默认关闭）、防火墙拦截、域名解析失败、网络彻底断开。建议先检查域名拼写是否正确，或用浏览器访问确认网站是否可达。

在线Ping和命令行Ping有什么区别？

命令行Ping直接从你的电脑发送ICMP包，在线Ping从工具站服务器发送。在线Ping适合在没有命令行环境（如手机）或需要从不同地理位置测试时使用。注意：本工具通过Web Worker模拟Ping行为，适合快速连通性检查。
