# 需求文档：Online Ruler（在线尺子/实际尺寸尺子）

## 1. 关键词分析
- 主关键词：online ruler / actual size ruler
- 月搜索量：~500,000+（online ruler）
- 辅助关键词：cm ruler online, inch ruler online, actual size ruler, virtual ruler, screen ruler
- 竞争度：中等（大量老旧网站，UI差，移动端不支持）
- 搜索意图：用户需要在屏幕上测量物体长度，需要一把实际尺寸的在线尺子

## 2. 竞品分析

### 竞品1: ruler.onl
- 功能：显示cm/inch刻度，需要校准
- 输出：屏幕上的尺子
- 缺点：UI老旧，广告多，移动端体验差

### 竞品2: iruler.net
- 功能：自动检测DPI显示尺子
- 输出：cm和inch双刻度
- 缺点：校准不精确，无分数刻度

### 竞品3: puzz.com/scaleruler
- 功能：简单显示尺子
- 输出：仅inch或仅cm
- 缺点：功能单一，无校准

## 4. 用户场景覆盖
1. 用户想量一个小物体（如硬币、手机）→ 放在屏幕上对比尺子
2. 用户想量屏幕上的东西 → 使用对角线测量
3. 用户在手机上需要尺子 → 移动端响应式
4. 用户需要精确测量 → 用信用卡校准DPI
5. 用户需要inch分数刻度（木工/手工）→ 1/16, 1/8, 1/4, 1/2刻度
6. 用户想知道像素和物理尺寸关系 → 像素/cm/inch对照表

场景覆盖率：6/6 = 100% ✅

## 5. 差异化
1. **双刻度同时显示**：cm和inch同时显示在尺子两侧
2. **inch分数刻度**：1/16, 1/8, 1/4, 1/2 四级精度
3. **信用卡校准**：用标准信用卡(85.6mm)精确校准DPI
4. **可拖动参考线**：拖动测量线精确测量
5. **对角线测量模式**：利用屏幕对角线自动校准
6. **深色主题**：现代UI，不伤眼
7. **移动端原生支持**：触屏拖动测量线
8. **像素/物理尺寸对照**：显示当前DPI信息

## 6. 技术方案
- 纯HTML+CSS+JS，无外部依赖
- Canvas绘制尺子刻度
- CSS media query响应式
- window.devicePixelRatio + 手动校准
- 深色主题（--bg:#0f172a）
- 响应式设计，375px不崩
- Schema.org SoftwareApplication + FAQ + Breadcrumb
