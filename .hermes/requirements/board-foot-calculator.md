# Board Foot Calculator 需求文档

## 一、关键词分析
- **关键词**: "board foot calculator", "board feet calculator", "lumber calculator"
- **预估月搜索量**: 15K-30K (英文)
- **竞品**: omnicalculator, inchcalculator, calculatorpro
- **搜索意图**: 木工/建筑行业用户需要计算木材的板英尺(board foot)数量，用于购买和定价

## 二、竞品功能清单
1. 基本板英尺计算: BF = (T × W × L) / 12 (英寸单位)
2. 多块板材批量计算（数量输入）
3. 单位切换: 英寸/英尺/毫米/厘米
4. 成本计算: 单价 × 板英尺数
5. 木材尺寸预设（2x4, 2x6, 2x8等名义尺寸 vs 实际尺寸）

## 三、用户场景
1. 木工购买木材时计算需要多少板英尺 — 100%覆盖
2. 估算木材成本（单价/板英尺） — 100%覆盖
3. 批量计算多块相同尺寸的板材 — 100%覆盖
4. 公制/英制单位切换 — 100%覆盖
5. 理解名义尺寸和实际尺寸的区别 — 80%覆盖

## 四、差异化
1. **名义尺寸 ↔ 实际尺寸自动转换** — 内置常见木材尺寸表(2x4=1.5"x3.5"等)，竞品大多只有手动输入
2. **多行批量计算** — 支持添加多行不同规格的板材，一次性汇总
3. **成本估算** — 不只算板英尺，还算总成本
4. **深色主题** — 竞品都是浅色，我们是深色主题

## 五、功能设计
### 模式1: 基本计算
- 输入: 厚度、宽度、长度、数量
- 单位选择: 英寸/英尺/mm/cm
- 输出: 板英尺数、立方英尺、立方米

### 模式2: 批量计算
- 多行输入不同规格
- 汇总总板英尺和总成本

### 模式3: 名义尺寸转换
- 选择名义尺寸(2x4, 2x6等)自动填入实际尺寸
- 计算板英尺

### 成本计算
- 输入单价($/BF)
- 输出总成本
