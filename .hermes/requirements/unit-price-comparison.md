# 单价比较计算器 - 需求文档

## 1. 需求验证

### 用户是谁？
- **CN用户**: 超市购物比价，不同包装规格单价对比
- **EN用户**: Grocery shoppers comparing unit prices of different package sizes

### 搜索量估计
- 关键词: unit price calculator, price comparison, bulk buy calculator
- 估计总搜索量: 6000+/月
- 竞品: 简单的单价计算器，不支持多商品对比

### 前端可行性
- [x] 纯前端可实现
- [x] 无API依赖

## 2. 功能规格

### 核心功能
1. 输入多个商品（价格+数量+单位），计算各自单价
2. 高亮最便宜选项，显示节省金额
3. 支持不同单位换算（kg/g/l/ml/个/打等）

### 交互元素（≥3）
- 添加商品行（价格+数量+单位选择）
- 计算按钮
- 结果：单价对比表+最划算高亮

## 3. 验收标准
- [ ] 多商品单价计算正确
- [ ] 单位换算正确
- [ ] 布局正常、移动端不崩
- [ ] EN版英文自然
