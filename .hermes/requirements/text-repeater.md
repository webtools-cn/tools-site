## 竞品分析
1. **pipi.tools/text-repeater** — 基础重复，支持分隔符和换行，界面简单
2. **symbolspy.com/text-repeater** — 支持emoji重复，有复制功能
3. **onlinetexttools.com/repeat-text** — 支持自定义次数和分隔符

### 功能清单
- [x] 输入文本
- [x] 设置重复次数 (1-10000)
- [x] 分隔符选择（空格/换行/逗号/自定义/无）
- [x] 递增模式（每次重复+1数字）
- [x] 实时预览结果
- [x] 字符/字数统计
- [x] 一键复制
- [x] 清空重置

## 用户场景
1. **聊天刷屏** — 在Discord/WhatsApp中重复文字制造效果（覆盖率90%+）
2. **测试数据生成** — 生成大量重复文本用于测试填充（覆盖率85%）
3. **编号生成** — 递增模式生成带序号的列表（覆盖率75%）
4. **占位符填充** — 生成占位文字填充模板（覆盖率70%）
5. **社交媒体** — 重复emoji或特殊字符（覆盖率65%）

场景覆盖率 ≥ 80% ✓

## 差异化
1. **递增编号模式** — 大多数竞品不支持，每次重复自动+1编号
2. **多种分隔符预设** — 空格/换行/逗号/制表符/自定义，竞品通常只有2-3种
3. **实时预览+统计** — 输入即显示结果，带字符数/字数/行数统计
4. **深色主题** — 比竞品更现代的UI体验
5. **安全上限** — 防止浏览器崩溃的智能限制（最多10000次）

## 技术方案
- 纯前端Vanilla JS
- 深色主题 (--bg:#0f172a)
- 实时计算+debounce
- toast通知
