# 目标心率计算器 / Target Heart Rate Calculator

## 一、关键词分析
- **英文关键词**: "heart rate calculator", "target heart rate calculator", "training heart rate zone calculator"
- **预估月搜索量**: 12,000-22,000/月（Google），health/fitness类高频搜索
- **中文关键词**: "目标心率计算器", "运动心率计算", "心率区间计算器"
- **预估月搜索量**: 1,000-3,000/月

## 二、竞品分析
1. **calculator.net/heart-rate-calculator** — 输入年龄+静息心率，输出5个训练区间+最大心率，Karvonen公式
2. **Mayo Clinic** — 简单表格，年龄→最大心率→目标区间(50%-85%)
3. **American Heart Association** — 简单公式220-年龄，展示目标区间
4. **Omni Calculator** — 多公式选择(Karvonen/百分比/Zoladz)，心率区间表

## 三、功能清单
1. ✅ 年龄输入 → 计算最大心率(220-年龄)
2. ✅ 静息心率输入(可选) → Karvonen公式计算更精准目标心率
3. ✅ 5个训练区间(Z1-Z5)：热身(50-60%)、燃脂(60-70%)、有氧(70-80%)、无氧(80-90%)、极限(90-100%)
4. ✅ 两种公式：简单百分比法 + Karvonen法(含静息心率)
5. ✅ 可视化心率区间条/进度条
6. ✅ 运动建议：每个区间对应的运动类型和效果
7. ✅ BMI联动(可选)：输入身高体重，额外给出健康建议

## 四、用户场景覆盖
1. 健身爱好者确定训练心率区间 ✅
2. 跑步者控制跑步强度 ✅
3. 减脂人群找燃脂心率区间 ✅
4. 初学者了解安全运动心率 ✅
5. 康复训练需要控制心率上限 ✅
覆盖率≥90%
