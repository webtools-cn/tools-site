# Ohm's Law Calculator（欧姆定律计算器）

## 一、关键词分析
- "ohms law calculator" — Google月搜索量约40K-100K（高搜索量电子工具）
- "ohm calculator" — 约10K-20K
- "voltage current resistance calculator" — 约5K-10K
- "欧姆定律计算器" — 中文月搜索量约2K-5K
- 结论：搜索量充足（>>1000），值得开发

## 二、竞品分析
1. **RapidTables Ohm's Law Calculator** — 简单输入两个值算第三个，支持功率计算
2. **Omni Calculator** — 多模式切换，含功率和能量
3. **Calculator.net** — 基础欧姆定律+功率

### 竞品功能清单
- [x] 输入电压(V)、电流(I)、电阻(R)中任意两个，算第三个
- [x] 功率(P)自动计算
- [x] 单位选择（mA/A, mV/V, Ω/kΩ/MΩ）
- [x] 公式展示
- [ ] 可视化电路图
- [ ] 功率耗散提示（安全提醒）
- [ ] 多种功率公式展示

## 三、用户场景
1. 电子爱好者设计电路时计算电阻值 — 覆盖
2. 学生学习欧姆定律做作业 — 覆盖
3. 工程师快速验证电路参数 — 覆盖
4. 维修人员排查电路故障 — 覆盖
5. 计算LED限流电阻 — 部分覆盖（可引导至专门工具）
6. 计算功率消耗/散热 — 覆盖

场景覆盖率：>85%

## 四、差异化
1. **实时计算**：输入任意两个值，第三个自动计算（无需点按钮）
2. **功率耗散安全提示**：当功率超过常见阈值（0.25W/0.5W/1W/2W/5W）时给出安全提醒
3. **公式可视化**：欧姆定律轮盘图（V=IR, P=VI, P=I²R, P=V²/R）动态展示当前使用的公式
4. **多单位支持**：V/mV/μV, A/mA/μA, Ω/kΩ/MΩ, W/mW
5. **电阻色环参考表**：内置4环/5环色环对照表
6. **深色主题**：与站点统一

## 五、技术方案
- 纯前端HTML+CSS+JS
- 输入3个值中任意2个，实时计算第3个+功率
- SVG绘制欧姆定律公式轮盘
- 纯本地计算，不上传数据
