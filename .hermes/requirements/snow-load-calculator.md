## 竞品分析

### 竞品1: Omni Calculator (snow-load)
- 功能：输入地面雪载荷 + 屋顶坡度 + 曝露/热系数 → 计算屋顶雪载荷
- 优点：界面清晰，多参数
- 缺点：广告多，移动端体验一般

### 竞品2: BuildingCodeCollege (snow load calculator)
- 功能：基于ASCE 7标准的完整雪载荷计算
- 优点：工程标准准确
- 缺点：界面老旧，参数复杂

### 竞品3: Calculatoratoz (Snow Load)
- 功能：基本雪载荷计算
- 优点：简单
- 缺点：缺少坡度修正，没有图表

## 功能清单
1. **地面雪载荷输入** (pg) - psf 或 kN/m²
2. **屋顶坡度输入** - 度数
3. **曝露系数选择** (Ce) - 完全暴露/部分暴露/遮蔽
4. **热系数选择** (Ct) - 采暖/不采暖/持续受热
5. **重要性系数选择** (I) - I/II/III/IV类建筑
6. **计算结果**：
   - 屋顶平直雪载荷 (pf)
   - 坡度修正后的设计雪载荷 (ps)
   - 坡度系数 (Cs)
7. **单位切换** - 英制(psF) / 公制(kN/m²)
8. **结果可视化** - 坡度影响图表
9. **安全余量建议**

## 用户场景
1. 建筑师/工程师计算屋顶雪载荷 → 覆盖
2. 房主检查屋顶能否承受积雪 → 覆盖（简化模式）
3. 承包商评估现有屋顶安全 → 覆盖
4. 学生学习ASCE 7雪载荷计算 → 覆盖（显示公式和中间步骤）
5. 建筑检查员快速验证 → 覆盖

场景覆盖率 > 80%

## 差异化
1. **ASCE 7标准**：基于ASCE 7-22最新标准，公式透明可见
2. **双单位系统**：psf/kN/m² 一键切换，实时转换
3. **中间步骤展示**：不只给结果，显示每步计算过程
4. **坡度系数图表**：可视化不同坡度对雪载荷的影响
5. **深色主题**：与竞品的白底不同，更护眼
6. **安全评级**：根据计算结果给出直观的安全等级

## 技术方案
- 纯前端HTML+CSS+JS
- Canvas绘制坡度影响曲线图
- ASCE 7公式：
  - pf = 0.7 × Ce × Ct × I × pg (平屋面雪载荷)
  - Cs = 坡度系数（根据ASCE 7表格/公式）
  - ps = Cs × pf (设计雪载荷)
  - 当坡度 > 70° 时，ps = 0
