# 钢筋计算器 (Rebar Calculator)

## 关键词分析
- **主关键词**: "rebar calculator" — 月搜索量约12,000-15,000 (EN)
- **长尾词**: "rebar spacing calculator", "rebar weight calculator", "rebar grid calculator"
- **CN关键词**: "钢筋计算器", "钢筋用量计算", "钢筋间距计算"

## 竞品分析
1. **inchcalculator.com/rebar-calculator** — 计算网格钢筋数量、长度、重量，支持英制/公制
2. **calculatorsoup.com** — 类似功能，计算rebar数量和总长度
3. **omnicalculator.com** — 更全面的rebar计算，含lap splice

## 功能清单
1. 输入板/墙尺寸（长×宽）和厚度
2. 选择钢筋规格（bar size #3-#11 / 公制直径）
3. 设置钢筋间距（on-center spacing）
4. 设置边缘距离（edge clearance/margin）
5. 选择网格类型：单层/双层（双向网格）
6. 计算输出：
   - 每方向钢筋数量
   - 每方向钢筋总长度
   - 钢筋总数量
   - 钢筋总重量（基于bar size单位重量）
   - 总面积/体积
   - 含lap splice（搭接长度）的总长度
   - 预估成本（可选）
7. 公制/英制单位切换
8. 可视化钢筋布局示意图（SVG）

## 用户场景覆盖
1. DIY浇筑混凝土板，需要买多少钢筋 ✓
2. 承包商估算钢筋材料成本 ✓
3. 工程师验算钢筋间距和数量 ✓
4. 柱/梁钢筋估算（简化版） ✓
5. 围墙基础钢筋计算 ✓

## 差异化
1. **SVG可视化布局** — 竞品大多只有数字，我们用SVG画出钢筋网格布局图
2. **搭接长度计算** — 大部分免费工具不含lap splice计算
3. **公制/英制双模式** — 同时支持中美标准钢筋规格
4. **重量+成本估算** — 一步到位算出需要买多少吨/磅钢筋和成本
5. **深色主题** — 竞品全是白色背景
