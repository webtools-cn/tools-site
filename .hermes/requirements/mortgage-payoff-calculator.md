# 需求文档：Mortgage Payoff Calculator（房贷提前还款计算器）

## 1. 关键词分析
- 主关键词：mortgage payoff calculator
- 月搜索量：~50,000
- 竞争度：中等（KD ~30-40）
- 搜索意图：用户想知道提前还清房贷能省多少利息、需要多少额外月供

## 2. 竞品分析

### 竞品1: Bankrate Mortgage Payoff Calculator
- 功能：输入贷款余额、利率、剩余期限、额外月供
- 输出：提前还清时间、节省利息、新还清日期
- 缺点：广告多、加载慢

### 竞品2: NerdWallet Early Mortgage Payoff Calculator
- 功能：额外月供/一次性额外付款/双周还款
- 输出：节省利息、提前还清月数
- 缺点：需要滚动很多、UI复杂

### 竞品3: Calculator.net Mortgage Payoff Calculator
- 功能：贷款余额、利率、剩余期限、额外付款方式
- 输出：对比表（原计划 vs 提前还款）
- 缺点：UI老旧

## 4. 用户场景覆盖
1. 用户想通过每月多还一些来提前还清房贷 → 额外月供模式
2. 用户拿到年终奖想一次性多还 → 一次性额外付款模式
3. 用户想改成双周还款加速还清 → 双周还款模式
4. 用户想对比不同策略 → 对比表+图表
5. 用户想知道具体哪天能还清 → 新还清日期
6. 用户想知道总共能省多少 → 节省利息+百分比

场景覆盖率：6/6 = 100% ✅

## 5. 差异化
1. **三种策略对比**：额外月供、一次性付款、双周还款，一键切换
2. **可视化图表**：用Canvas绘制原计划vs提前还款的余额下降曲线
3. **摊还对比表**：前12个月详细对比，一目了然
4. **利息节省百分比**：直观显示节省比例
5. **纯前端无广告干扰**：深色主题、快速加载

## 6. 技术方案
- 纯HTML+CSS+JS，无外部依赖
- Canvas绘制余额对比图表
- 深色主题（--bg:#0f172a）
- 响应式设计，375px不崩
- Schema.org SoftwareApplication + FAQ + Breadcrumb
