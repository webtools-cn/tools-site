# 需求文档：时薪转年薪计算器 (Hourly to Salary Calculator)

## 一、关键词分析
- **关键词**: "hourly to salary calculator" / "hourly wage to annual salary" / "时薪转年薪计算器"
- **预估月搜索量**: 50,000-100,000 (英文) + 5,000-10,000 (中文)
- **搜索意图**: 用户想知道自己的时薪对应多少年薪/月薪/周薪，用于求职谈薪、比较工作offer、评估收入水平
- **竞品**: 
  - calculator.net/hourly-to-salary.html — 功能全但UI老旧
  - investopedia.com — 理论为主，计算器简陋
  - indeed.com/career-advice — 有计算器但嵌在文章中
- **差异化**: 深色现代UI + 实时多维度输出（年薪/月薪/周薪/日薪/时薪对比）+ 工作时间灵活配置 + 税前税后估算 + 多种工时模式（全职/兼职/合同工）

## 二、功能规格

### 核心功能
1. 输入时薪 → 实时计算年薪、月薪、周薪、日薪
2. 可配置每周工作小时数（默认40）、每年工作周数（默认52）、每周工作天数
3. 支持三种计算模式：标准全职（40h/52w）、兼职自定义、合同工（按小时总价）
4. 附加显示：时薪 → 分钟薪，方便直观对比
5. 输入年薪反算时薪（双向计算）

### 交互元素（≥3）
- 时薪输入框 + 货币选择
- 每周工作小时数滑块/输入
- 每年工作周数输入
- 每周工作天数输入
- 实时计算结果展示（年薪/月薪/周薪/日薪/分钟薪）
- 年薪反算时薪的切换按钮

### 技术方案
- 纯前端JS计算
- 实时更新（input事件）
- 支持美元/欧元/英镑/人民币等常见货币符号

## 三、EN版本差异
- EN: "Hourly to Salary Calculator"，用美元为主，术语：annual salary, weekly pay, daily wage
- CN: "时薪转年薪计算器"，用人民币为主，术语：年薪、月薪、周薪、日薪

## 四、验收标准
- [ ] 输入时薪→输出年薪/月薪/周薪/日薪正确
- [ ] 双向计算（输入年薪反算时薪）
- [ ] 布局正常、移动端375px不崩
- [ ] EN版英文自然、无中文
- [ ] 有Schema、无假评分
- [ ] 深色主题
