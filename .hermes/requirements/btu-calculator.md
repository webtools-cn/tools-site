## 三、用户场景覆盖
1. 选购空调 — 输入房间面积和条件，得到推荐BTU → 覆盖
2. 选购暖气/加热器 — 制热BTU计算 → 覆盖
3. 不同绝缘质量 — 好/平均/差 → 覆盖
4. 日照影响 — 朝南/朝北/强烈日照 → 覆盖
5. 人数影响 — 每人额外~400 BTU制冷 → 覆盖
6. 厨房调整 — 厨房额外4000 BTU → 覆盖
7. 天花板高度 — 标准8ft vs 高天花板 → 覆盖
8. 面积单位 — 平方英尺/平方米切换 → 覆盖
9. 推荐吨位换算 — BTU → 吨(Ton) → 覆盖
10. 推荐瓦特换算 — BTU → W → 覆盖

覆盖率: 10/10 = 100% ✅

## 四、差异化
1. **全因素综合计算** — 竞品多数只算面积，本工具集成绝缘/日照/人数/厨房/天花板5大调整因子
2. **制冷+制热双模式** — 大部分竞品只算制冷
3. **BTU/吨/瓦特三重输出** — 方便不同场景选购
4. **可视化推荐区间** — 显示推荐范围(min-max)，不只一个数字
5. **房间类型快速预设** — 客厅/卧室/厨房/办公室等一键选择
6. **中文+英文双语** — 大部分竞品只有英文

## 五、技术方案
- 纯前端HTML+JS，零后端
- 深色主题 (--bg:#0f172a)
- 计算公式: 基础BTU = 面积(sqft) × 20~25 BTU/sqft (根据绝缘质量)
- 调整因子: 天花板高度、日照、人数、厨房、房间类型
- 输出: 推荐BTU范围、推荐吨位、推荐瓦特、空调匹数(HP)
