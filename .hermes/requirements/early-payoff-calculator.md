# 需求文档：提前还款计算器 (Early Payoff Calculator)

## 一、关键词分析
- **关键词**: "early payoff calculator" / "loan payoff calculator" / "提前还款计算器"
- **预估月搜索量**: 8,000-15,000 (英文) + 2,000-5,000 (中文)
- **搜索意图**: 用户有贷款（房贷/车贷/学生贷等），想知道提前还款能省多少利息、缩短多少期限
- **竞争程度**: 中等，但大多数竞品功能单一

## 二、竞品分析

### 竞品1: Calculator.net (early-payoff)
- 功能: 输入余额、利率、月供、额外月供 → 计算提前还清月数和节省利息
- 缺点: 只有额外月供模式，无一次性还款模式，无对比图表

### 竞品2: Bankrate (loan-payoff-calculator)
- 功能: 输入贷款信息+额外还款 → 看新还款时间表
- 缺点: 无可视化图表，界面复杂，广告多

### 竞品3: NerdWallet (early-payoff)
- 功能: 简单的提前还款计算
- 缺点: 功能太简单，无多场景对比

## 三、差异化设计

1. **双模式**: 额外月供模式 + 一次性还款模式，两种都能算
2. **多贷款类型**: 房贷/车贷/学生贷/个人贷款，预设不同利率范围
3. **节省可视化**: 用纯CSS柱状图对比"原计划 vs 提前还款"的利息/时间
4. **新还款时间表**: 生成简要的还款时间表（前12个月+关键节点）
5. **纯前端**: 无需注册，数据不上传

## 四、用户场景

| # | 场景 | 覆盖 |
|---|------|------|
| 1 | 用户有房贷，想每月多还$200看能省多少 | ✅ 额外月供模式 |
| 2 | 用户有年终奖，想一次性还$10,000 | ✅ 一次性还款模式 |
| 3 | 用户想知道提前还清后总利息节省多少 | ✅ 对比展示 |
| 4 | 用户想知道能提前多少个月还完 | ✅ 时间对比 |
| 5 | 用户有车贷/学生贷，同样想算 | ✅ 贷款类型选择 |
| 6 | 用户想看新的还款时间表 | ✅ 时间表生成 |
| 7 | 用户想同时算额外月供+一次性还款组合 | ✅ 组合模式 |

覆盖率: 7/7 = 100%

## 五、技术设计

### 输入
- 贷款类型 (select: 房贷/车贷/学生贷/个人贷款)
- 当前贷款余额 ($)
- 年利率 (%)
- 剩余期限 (月)
- 当前月供 ($, 可选-自动计算)
- 提前还款模式 (radio: 额外月供 / 一次性还款 / 组合)
- 额外月供金额 ($) (模式相关)
- 一次性还款金额 ($) (模式相关)

### 输出
- 原计划总利息 vs 提前还款总利息
- 节省利息金额
- 原计划还清时间 vs 提前还款还清时间
- 提前还清月数
- 新月供金额 (如适用)
- 纯CSS柱状图对比
- 简要还款时间表

### 计算逻辑
1. 标准摊还公式: M = P * r * (1+r)^n / ((1+r)^n - 1)
   - P=本金, r=月利率, n=月数
2. 提前还款: 逐月递推计算，额外月供加入本金偿还
3. 一次性还款: 从余额中直接扣除，重新计算剩余时间
