# 轮胎尺寸计算器 / Tire Size Calculator

## 需求分析

### 关键词搜索量
- "tire size calculator": 月搜索量 ~90,500 (Google Keyword Planner估算)
- "tire size comparison": ~22,200
- "tire size converter": ~9,900
- "轮胎尺寸计算器": ~1,300

### 竞品分析
1. **tiresize.com/calculator/** — 行业标杆，输入两个轮胎尺寸，对比直径、宽度、侧壁高度、周长、转速差异
2. **tirebuyingguide.com** — 基本对比功能
3. **1010tires.com/tools/tire-size-calculator** — 对比+速度计偏差

### 功能清单
1. 输入两个轮胎尺寸（如 225/45R17 vs 235/40R18）
2. 解析轮胎规格格式：宽度/扁平比R轮辋直径
3. 计算：
   - 轮胎直径 (mm/in)
   - 轮胎宽度 (mm/in)
   - 侧壁高度 (mm/in)
   - 周长 (mm/in)
   - 每公里转数 (revs/km)
   - 时速60mph/h时的实际速度偏差 (%)
4. 可视化对比两个轮胎尺寸（侧视图SVG）
5. 单位切换：公制/英制
6. 常见轮胎尺寸速查表

### 用户场景覆盖
1. 换轮胎时对比新旧尺寸是否兼容 ✓
2. 升级轮毂时确认新轮胎是否合适 ✓
3. 计算速度表偏差 ✓
4. 查看轮胎实际尺寸参数 ✓
5. 单位换算（公制/英制） ✓

### 差异化
- 深色主题 + SVG可视化轮胎侧视图对比
- 实时计算，输入即显示结果
- 速度表偏差百分比醒目提示
- 支持公制/英制切换
- 中文+英文双语
