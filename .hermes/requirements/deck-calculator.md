# Deck Calculator 需求文档

## 工具名称
deck-calculator（露台甲板计算器）

## 关键词搜索量
- "deck calculator": ~18,000月搜索量（英文）
- "deck material calculator": ~8,000
- "deck board calculator": ~5,000
- 合计相关关键词月搜索量 > 30,000

## 竞品分析
1. **Decks.com Deck Calculator** — 输入面积算板数，不支持多区域、无成本估算
2. **HomeAdvisor Deck Cost Calculator** — 偏成本估算，无材料清单
3. **Trex Decking Calculator** — 仅适用于复合材料，品牌绑定

## 差异化
- 支持**多区域面积汇总**（矩形+圆形，多个区域相加）
- 支持**木材/复合材料**两种材质选择
- 含**标准板材尺寸预设**（5/4x6, 2x6, 2x4）+自定义
- **间距计算**（板与板之间间隙自动计入）
- **浪费率系数**（默认10%可调）
- **成本估算**（含税费）
- **公制/英制单位切换**
- **螺丝/隐藏扣件数量估算**
- 纯前端，零依赖，隐私安全

## 用户场景覆盖率
1. ✅ 建露台前估算需要多少块地板
2. ✅ 多个不规则区域合并计算
3. ✅ 不同板材尺寸对比用量
4. ✅ 估算材料总成本
5. ✅ 估算螺丝/扣件数量
6. ✅ 公制/英制切换（国际用户）
7. ✅ 含浪费率的实际采购量

## 功能清单
1. 输入：多区域面积（长×宽 或 直径），自动汇总
2. 选择：板材类型（木材5/4x6 / 2x6 / 2x4 / 复合材料）
3. 输入：板材实际宽度、间隙、浪费率
4. 输入：单价、税率
5. 输出：总面积、板材数量、板材总长度、螺丝/扣件数、材料成本（含税）
6. 单位切换：英尺/米
7. 成本明细展示
