# EV充电成本计算器 - 需求文档

## 1. 需求验证

### 用户是谁？
- **CN用户**: 电动车车主，需要计算在家/公共充电桩充电成本
- **EN用户**: EV owners calculating charging costs at home vs public stations

### 搜索量估计
- 关键词: EV charging cost calculator, electric car charging cost
- 估计总搜索量: 8000+/月
- 竞品: 各种EV网站有简单计算器，功能不全

### 竞品分析
- 竞品1: 各种EV网站简单计算器 - 只算单次，不对比油车
- 我们的优势: 支持家用/公共充电对比、年度成本估算、与燃油车对比

### 前端可行性
- [x] 纯前端可实现
- [x] 无API依赖
- [x] 无CORS问题
- [x] 无数据隐私风险

## 2. 功能规格

### 核心功能
1. 输入电池容量(kWh)、电价、充电效率 → 计算单次充满成本
2. 输入月行驶里程、能耗(kWh/100km) → 计算月/年充电成本
3. 与燃油车对比：输入油耗和油价 → 显示年度节省

### 交互元素（≥3）
- 电池容量输入 + 电价输入 + 充电效率滑块
- 月行驶里程 + 能耗输入
- 燃油车对比输入（油耗+油价）
- 结果卡片：单次成本/月成本/年成本/年节省
