# User-Agent Parser 需求文档

## 搜索量估算
- "user agent parser": ~12,000/月
- "UA解析": ~2,000/月
- "user agent string decoder": ~5,000/月
- "浏览器UA查询": ~3,000/月
- 合计: ~22,000+/月 ✅

## 竞品分析
| 竞品 | 优点 | 缺点 |
| useragentstring.com | 老牌，数据全 | UI极简陋，无响应式，无中文 |
| whatismybrowser.com | 功能丰富，API | 需要注册，广告多 |
| user-agents.net | 数据库大 | 纯数据库，无解析交互 |

## 差异化
1. 实时解析+可视化卡片（图标化展示）
2. 双向转换（解析+生成）
3. 一键检测当前UA
4. 常见UA预设库
5. 深色主题
6. 中英双语
