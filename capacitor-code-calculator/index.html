💡 电容代码说明

陶瓷电容使用三位数字代码标记电容值。前两位是有效数字，第三位是10的幂次（单位：pF）。

解析规则

  • 代码 = XY × 10^Z pF
  • 例：104 = 10 × 10^4 = 100,000 pF = 100 nF = 0.1 μF
  • 例：472 = 47 × 10^2 = 4,700 pF = 4.7 nF
  • 代码"0"或"000"表示0pF（跳线）

常见代码对照表

  • 101 = 100pF | 102 = 1nF | 103 = 10nF (0.01μF)
  • 104 = 100nF (0.1μF) | 105 = 1μF
  • 221 = 220pF | 331 = 330pF | 471 = 470pF
  • 222 = 2.2nF | 472 = 4.7nF | 682 = 6.8nF
  • 223 = 22nF | 473 = 47nF | 683 = 68nF

公差字母含义

  • J = ±5% (最常见) | K = ±10% | M = ±20%
  • F = ±1% | G = ±2%
  • B/C/D = 极低公差(用于高频)
