📖 关于样本量计算

样本量是市场调研和学术研究中确保结果可靠性的关键因素。样本量越大，误差越小，但成本也越高。

本计算器使用标准公式：n = Z²×p×(1-p) / e²（无限总体）或 n = (N×Z²×p×(1-p)) / (e²×(N-1) + Z²×p×(1-p))（有限总体修正）。

其中Z值对应置信水平：99%=2.576，95%=1.96，90%=1.645。
