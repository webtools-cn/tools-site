常见问题

Free ToolBase 真的免费吗？

是的，全部 1300+ 工具完全免费，无需注册。我们通过广告收入维持网站运营。

我的数据安全吗？

绝对安全。所有处理都在你的浏览器中完成，我们不会将你的数据上传、存储或传输到任何服务器。你的文件和文本永远不会离开你的设备。

可以请求新工具吗？

当然可以！在我们的 GitHub Issues 页面提交功能请求，我们会考虑将其加入工具库。

你们提供 API 吗？

目前暂不提供，但我们正在探索这个选项。如果你感兴趣，可以通过 GitHub Issues 告诉我们。

回复时间

我们通常在 48 小时内回复邮件。GitHub Issues 会定期审核。如有紧急事项，请使用邮箱联系。
