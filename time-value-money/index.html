📖 使用教程

第一步：选择求解变量

从下拉菜单中选择要求解的变量。灰色输入框表示该变量将由计算器求解，您需要填写其他四个参数。

第二步：输入已知参数

  • PV (现值)：当前的本金或投资金额。正数表示投资，负数表示借款。
  • FV (终值)：未来的目标金额。0表示到期时无余额（如贷款还清）。
  • PMT (年金)：每期固定支付金额。负数表示支出（如还款），正数表示收入（如领取年金）。
  • 年利率：年化利率百分比。计算器会自动根据期数单位换算为每期利率。
  • 总期数：付款总次数。例如10年按月付款=120期。

第三步：解读结果

点击计算后，结果区显示求解变量的值和所有参数汇总。常见应用场景：

  • 贷款计算（求PMT）：输入贷款金额(PV)、利率、期数、FV=0 → 得到每月还款额
  • 投资规划（求FV）：输入当前投资(PV)、每月定投(PMT)、利率、期数 → 得到最终金额
  • 目标储蓄（求NPER）：输入目标(FV)、现有(PV)、月存(PMT)、利率 → 得到所需月数

💡 TVM核心公式

货币时间价值的基本关系：PV × (1+r)^n + PMT × [(1+r)^n - 1]/r + FV = 0

其中 r 为每期利率，n 为期数。五个变量已知四个，即可求解第五个。这是金融计算器（如BA II Plus）的核心功能，也是CFA/FRM等金融考试必考内容。

❓ 常见问题 (FAQ)

什么是货币时间价值(TVM)？

货币时间价值(Time Value of Money)是金融学核心概念：今天的1元钱比明天的1元钱更值钱，因为今天的钱可以投资产生收益。TVM计算器帮助您计算现值(PV)、终值(FV)、年金(PMT)、利率和期数之间的关系。

PV、FV、PMT分别代表什么？

PV(Present Value)现值：未来现金流的当前价值；FV(Future Value)终值：当前投资在未来某时的价值；PMT(Payment)年金：每期固定支付/收入金额。这三个变量加上利率和期数，构成了TVM五大核心变量。

如何用TVM计算贷款月供？

输入贷款金额作为PV(正值)，贷款年利率/12作为月利率（选择「月」为单位），贷款月数作为NPER，FV设为0，选择「计算PMT」。计算结果即为每月还款额。例如：30万贷款、年利率4.5%、30年(360期)，月供约1,520元。

年金先付和后付有什么区别？

先付年金(期初付款)：每期开始时支付，如房租、保险。后付年金(期末付款)：每期结束时支付，如贷款还款、工资。同样参数下先付年金的终值更高、现值也更高。本计算器默认使用后付模式。
