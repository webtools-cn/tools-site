关于PDF元数据

什么是PDF元数据？

PDF元数据是嵌入在PDF文件中的描述性信息，包括文档属性、创建历史、安全设置等。这些信息在文件创建时由生成软件自动添加，可以帮助了解文档的来源和属性。

常见元数据字段

  • Title - 文档标题
  • Author - 作者名称
  • Subject - 文档主题
  • Keywords - 关键词
  • Creator - 创建该PDF的软件
  • Producer - PDF生成引擎
  • CreationDate - 创建日期
  • ModDate - 最后修改日期
  • Pages - 页数
  • PDF Version - PDF格式版本
  • Encrypted - 是否加密
  • File Size - 文件大小

隐私说明

PDF解析完全在您的浏览器中进行，文件内容不会上传到任何服务器。解析完成后数据仅保留在您的浏览器内存中。
