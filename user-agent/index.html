📖 什么是User Agent？

User Agent（用户代理）是浏览器在访问网站时发送的一段标识字符串。它包含了关于浏览器类型、版本、操作系统、设备类型和渲染引擎等信息。网站服务器可以根据User Agent来优化页面显示、统计访客数据或进行兼容性处理。

支持解析的内容

  • 浏览器: Chrome, Firefox, Safari, Edge, Opera, IE, Samsung Internet, UC Browser, Brave, Vivaldi 等
  • 操作系统: Windows, macOS, Linux, iOS, Android, ChromeOS 等
  • 设备类型: Desktop, Mobile, Tablet, Bot/Crawler
  • 渲染引擎: Blink, WebKit, Gecko, Trident 等
  • 爬虫识别: Googlebot, Bingbot, Baiduspider, YandexBot 等

完全免费，无需注册，无需下载。所有功能在浏览器本地运行，数据不会上传到任何服务器。

数据会经过服务器吗？

不会。本工具是纯前端应用，所有解析操作都在您的浏览器中本地完成，数据绝不离开您的设备。

User Agent字符串会泄露隐私吗？

User Agent本身不包含个人身份信息（如IP地址、地理位置等），它只是浏览器和设备的技术标识。不过，结合其他信息（如IP地址）可以形成浏览器指纹。本工具在本地解析，不会收集任何数据。

支持手机端使用吗？

支持。采用响应式设计，可以在手机、平板和电脑上正常使用。

为什么不同浏览器的UA格式不一样？

历史原因。早期浏览器通过UA标识来声明兼容性，导致现在的UA字符串中常包含多个浏览器名称。例如Chrome的UA中包含"Safari"和"KHTML, like Gecko"，这是因为Chrome使用WebKit/Blink引擎并兼容这些标识。
