💡 关于电阻分压

电阻分压器是最基本的电路之一。两个电阻串联，输出电压从中间取出。

公式

Vout = Vin × R2 / (R1 + R2)

分压比 = R2 / (R1 + R2)

常见应用

  • Arduino 5V → 3.3V 电平转换（R1=1.7kΩ, R2=3.3kΩ）
  • 传感器信号调理
  • ADC（模数转换）参考电压
  • 电池电压监测

注意事项

  • 负载电阻RL会与R2并联，改变分压比
  • 选择较大的电阻值可降低功耗，但会增加噪声敏感性
  • 电阻精度影响输出电压精度，建议使用1%精度电阻
