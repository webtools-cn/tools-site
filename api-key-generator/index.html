📋 常见问题

什么是API密钥？它有什么用途？

API密钥是用于识别和验证调用API接口的应用程序或用户的唯一标识符，就像一把"数字钥匙"。常见用途包括访问OpenAI API（ChatGPT）、Stripe支付网关、Google Maps地图服务、AWS云服务、Twilio短信等。所有主流SaaS平台都使用API密钥进行身份验证。

生成的API密钥安全吗？

绝对安全。本工具使用浏览器内置的crypto.getRandomValues()真随机数生成器（CSPRNG），而非Math.random()伪随机。所有生成操作在您的浏览器本地完成，密钥绝不经过网络传输，也不会被上传到任何服务器。您可以断开网络连接后正常使用。

应该选择什么字符集？

字母+数字（默认）适合绝大多数API服务，如OpenAI的sk-格式密钥；十六进制适合需要兼容UUID格式或旧系统的场景；纯字母便于人工阅读和输入；全字符（含特殊符号）提供最高安全强度，但某些API可能不支持特殊字符。不确定时使用默认的字母+数字即可。

API密钥长度设置多少合适？

推荐32位以上。OpenAI使用sk-前缀+48位，Stripe使用sk_live_前缀+24位，GitHub使用ghp_前缀+40位。对于高安全性场景（如支付网关），建议64-128位。密钥越长安全性越高，但需确保目标API接受该长度。

前缀有什么作用？

前缀（如sk-、pk-）帮助快速识别密钥类型：sk-表示Secret Key（私密密钥，不应公开），pk-表示Public Key（公开密钥），sk_live_表示生产环境密钥。前缀不影响安全性，但能提高密钥管理的便利性。
