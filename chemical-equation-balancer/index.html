  • 配平基于线性代数法，保证数学上精确

🔬 常见反应类型

  • 化合反应：A + B → AB（如 H₂ + O₂ → H₂O）
  • 分解反应：AB → A + B（如 CaCO₃ → CaO + CO₂）
  • 置换反应：A + BC → AC + B（如 Fe + CuSO₄ → FeSO₄ + Cu）
  • 复分解反应：AB + CD → AD + CB（如 NaCl + AgNO₃ → AgCl + NaNO₃）
  • 氧化还原反应：涉及电子转移（如 KMnO₄ + HCl）
  • 酸碱中和：酸 + 碱 → 盐 + 水（如 HCl + NaOH → NaCl + H₂O）
