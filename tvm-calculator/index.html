📖 TVM 公式说明

货币时间价值（Time Value of Money）核心公式：

FV = PV × (1 + r)^n + PMT × [(1 + r)^n - 1] / r

其中：PV = 现值，FV = 终值，r = 每期利率，n = 期数，PMT = 每期支付

🎯 五种计算模式

计算终值 FV：给定现值、利率、期数和年金，计算未来价值。

计算现值 PV：给定终值、利率、期数和年金，反推现在需要投入多少。

计算利率 r：给定PV、FV、期数和年金，求年化收益率（使用牛顿迭代法）。

计算期数 n：给定PV、FV、利率和年金，求需要多少期才能达到目标。

计算年金 PMT：给定PV、FV、利率和期数，求每期需要投入多少。

❓ 常见问题

TVM计算器可以用于哪些场景？

TVM计算器适用于退休规划、教育基金、贷款还款、投资回报分析等几乎所有涉及货币时间价值的场景。

利率是年利率吗？

是的，默认输入年利率。如果你的计算周期不是年，需要相应调整利率和期数（如月利率 = 年利率/12，期数 = 年数×12）。

年金PMT什么时候用？

当你每期定期存入或取出固定金额时使用。正值表示存入（如每月定投），负值表示取出（如每月领取养老金）。默认为0表示没有定期现金流。

数据安全吗？
