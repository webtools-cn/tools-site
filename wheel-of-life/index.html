生活平衡轮的计算逻辑

本工具的核心计算逻辑：

  • cx = size / 2
  • cy = size / 2
  • radius = size * 0.38
  • r = (radius * level) / 5
  • angle = (Math.PI * 2 * i) / n - Math.PI / 2
  • x = cx + Math.cos(angle) * r
