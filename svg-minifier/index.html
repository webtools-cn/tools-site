📖 SVG 压缩优化说明

🔧 压缩规则

  • 移除注释 — 删除所有 <!-- ... --> 注释
  • 压缩空白 — 移除多余空格、换行、缩进
  • 移除元数据 — 删除 <metadata>、<title>、<desc> 等编辑器生成的元数据标签
  • 精简小数 — 将路径坐标等数值保留3位小数（如 12.345678 → 12.346）
  • 移除默认属性 — 删除值为默认值的属性（如 version="1.1"、fill="black"）
  • 移除空属性 — 删除值为空的属性（如 class=""、data-name=""）

💡 使用建议

建议保留原始SVG备份。本工具适合生产环境部署前对SVG进行最终优化。对于图标类小型SVG，压缩效果尤其明显（可达50-70%）。
