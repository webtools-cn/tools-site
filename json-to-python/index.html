❓ 常见问题

JSON转Python字典支持哪些数据类型映射？

自动映射：string→str、number→int/float、boolean→bool、null→None、array→list、object→dict。JSON中的ISO日期字符串会自动转换为datetime对象。嵌套对象会被递归处理为完整的字典结构。

生成的Python代码可以直接使用吗？

可以。生成的代码使用标准Python字典字面量语法，可直接复制到您的Python项目中。兼容Python 3.6+，纯字典模式也兼容Python 2.7+。无需任何外部依赖。

如何处理JSON中的null值？

JSON中的null值会转换为Python的None关键字。在类型注解模式下，null字段会标记为Optional[Any]。工具还支持通过配置将null替换为默认空值。

支持嵌套JSON对象吗？

完全支持。嵌套对象会被递归转换为Python嵌套字典结构，保留原始数据的层级关系和缩进。数组中的对象也会被正确处理，生成包含字典结构的列表元素。

我的数据安全吗？

绝对安全。本工具100%在您的浏览器中运行，JSON数据完全在本地内存中处理，不会上传到任何服务器。处理完成后数据立即清除，离线也能使用。
