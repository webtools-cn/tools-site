💡 说明

什么是音频波形？

音频波形是声音信号的图形化表示，横轴表示时间，纵轴表示振幅（音量）。波形的起伏反映了声音的强弱变化。

如何处理？

本工具使用 Web Audio API 解码音频文件并提取波形数据，所有处理在浏览器本地进行，文件不上传到服务器。

支持哪些格式？

支持浏览器支持的所有音频格式，包括 MP3、WAV、OGG、M4A (AAC)、FLAC 等。推荐使用 MP3 或 WAV 格式。

如何使用音频波形可视化工具

使用音频波形可视化工具非常简单，只需三个步骤：

  1. 上传音频
    点击上传区域选择或拖拽音频文件到页面，工具会在浏览器本地解码音频并自动生成波形图。
  2. 预览与调整（可选）
    点击播放按钮试听音频，实时查看播放进度标记。可自定义波形颜色、背景颜色、波形粗细和波峰缩放。
  3. 导出图片
    对波形效果满意后，点击"导出为图片 (PNG)"保存当前波形图。可无限次使用，完全免费。
