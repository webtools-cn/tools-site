📖 关于FIRE和4%原则

什么是FIRE？

FIRE = Financial Independence, Retire Early（财务独立，提前退休）。核心理念：通过高储蓄率（50%+）和理性投资，在传统退休年龄前积累足够资产，实现不再为钱工作的自由。

4%原则详解

三一大学研究（Trinity Study）发现：如果每年从投资组合提取不超过4%的初始本金（按通胀调整），退休资产有95%以上概率在30年内不耗尽。

公式：FIRE数字 = 年支出 ÷ 安全提取率

不同提取率的FIRE乘数

  • 提取率3.0% → 乘数33.3倍（极其保守）
  • 提取率3.5% → 乘数28.6倍（较保守）
  • 提取率4.0% → 乘数25倍（标准FIRE）
  • 提取率4.5% → 乘数22.2倍（较激进）
  • 提取率5.0% → 乘数20倍（激进，风险较高）

FIRE类型

  • Lean FIRE：极简生活，年支出<$25,000，目标$625,000
  • Regular FIRE：正常生活，年支出$40,000-60,000，目标$1-1.5M
  • Fat FIRE：富足生活，年支出>$100,000，目标$2.5M+
  • Coast FIRE：已有足够本金，不需再存，等待复利达到目标
  • Barista FIRE：半退休，做兼职覆盖部分支出
