什么是JSON Schema？

JSON Schema是描述JSON数据结构的标准规范（RFC 8927），用于API文档、数据验证、IDE自动补全等场景。

生成的Schema遵循哪个版本？

Draft-7版本，兼容性最好、使用最广泛。

如何判断必填字段？

所有出现的字段默认必填。null值字段标记为可选。用完整示例获得准确Schema。

数组元素如何推断？

非空数组根据第一个元素推断类型。混合类型使用anyOf。空数组默认items为空对象。
