波长与频率的关系

波长(λ)和频率(f)是电磁波的两个基本参数，它们之间的关系由公式 λ = c / f 决定，其中c是真空中的光速(299,792,458 m/s)。频率越高，波长越短；频率越低，波长越长。

常见电磁波波长范围：无线电波(km~m级)、微波(cm~mm级)、红外线(μm级)、可见光(380-780nm)、紫外线(nm级)、X射线(pm级)。

本工具支持频率→波长和波长→频率双向计算，自动选择最合适的单位显示结果，也支持手动指定输出单位。内置AM广播、FM广播、WiFi 2.4GHz/5GHz、可见光等常见信号预设，方便快速查询。

❓ 关于波长计算器

波长和频率的关系是什么？

波长(λ)和频率(f)的关系由公式 λ = c / f 决定，其中c是光速(299,792,458 m/s)。频率越高，波长越短；频率越低，波长越长。例如1MHz的AM广播波长约300米，而5GHz的WiFi波长仅约6厘米。

如何选择合适的波长单位？

根据波长大小选择合适单位：无线电波用km/m，微波用cm/mm，红外线用μm，可见光和紫外线用nm。本工具会自动推荐合适单位，也可手动选择。

这个计算器支持哪些预设？

内置5种常见信号预设：AM广播(1MHz)、FM广播(100MHz)、WiFi 2.4GHz、WiFi 5GHz、可见光(500THz)。点击预设按钮即可快速计算对应波长。

计算结果准确吗？

本工具使用精确光速值 c = 299,792,458 m/s 进行计算，所有运算在浏览器本地完成，结果精确可靠。支持科学计数法显示，方便查看极大或极小的数值。
