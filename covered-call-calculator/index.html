Covered Call计算器的计算逻辑

本工具的核心计算逻辑：

  • maxProfit = (strike - stock) + premium
  • maxProfitPct = (maxProfit / stock) * 100
  • breakeven = stock - premium
  • annualReturn = (premium / stock) * (365 / days) * 100
  • premiumYield = (premium / stock) * 100
  • downsideProtection = (premium / stock) * 100
