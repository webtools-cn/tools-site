❓ IATA代码和ICAO代码有什么区别？

IATA代码是3个字母，主要用于机票预订和行李标签（如PEK）。ICAO代码是4个字母，主要用于空中交通管制和飞行计划（如ZBAA）。普通旅客只需关注IATA代码即可。

❓ 为什么有些代码看起来和城市名无关？

有些代码来自历史名称（如ORD=芝加哥奥黑尔，原名Orchard Field），有些因为原代码已被占用（如BJS不再是北京的城市代码，改用PEK）。
